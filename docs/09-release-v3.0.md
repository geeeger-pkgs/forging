|---|---|---|---|
| L1 | 词缀按档位分池（v2.1 起悬挂） | ✅ 做到 | `prospect`（勘探）只对 T4+ 矿脉生效 → 同样只在 T4+ 装备的池里出现（低档不再摇到"死词缀"） |
| L2 | 行囊治理 / 实例级自动回收（v2.1 起悬挂） | ✅ 做到 | 实例级阈值回收（不碰已装备/在制消耗件、离线不结算）+ 行囊排序（完美度/强化/档位）+「整理」（同 id 只留最优） |

### 2. 深渊深化（玩家感知最强）

- **层词条**：每 5 层一循环，节奏为「3 层常规 → 1 层喘息（裂隙：门槛 ×0.94、结晶 ×0.8）→ 1 层墙（富矿：门槛 ×1.06、首通结晶 ×1.5）」。权重倾斜层（迅捷/丰饶/试炼）让"为这一层重配装"成为真实决策。
- **连打**：一次点击从下一层起逐层判定，通过就继续、遇到第一个不达标的层停下；**首通奖励逐层照发**（不存在跳过层，也就没有奖励黑洞）；整次只花 1 点体力。
- **实算影响**：可达层从 10/26/35 变为 **9/24/34**（墙的存在感），结晶平均倍率 ×1.06（首通）。

### 3. 证据链（"文档数字 = 脚本输出 = 内容表"）

- `sim-expedition` / `sim-season` / `sim-abyss` 三个脚本**改为读 `data/*.json`**（此前硬编码，会与表静默漂移）；`sim-expedition` 新建 JSON 产物。
- 新增 `sim-codex`（图鉴分区门槛实算）与 `report-content`（内容规模表由脚本生成）。
- 测试新增**反向静态检查**：脚本内不得出现被审计的数值字面量（`tests/v30.test.ts` F10）。
- 修掉 `sim-abyss` 的历史文案残留 6 处（growth 2.225× → 2.126× 等）。

### 4. 收口与质量

- **图鉴位图**：逗号串 → 216 bit 位图（**27B / base64 36 字符**，原约 3.4KB）；分区门槛里程碑（物品/配方/词缀/伙伴/遗物/矿场各自达标）。
- **收尾 13 项**：券类错误进预检、窄屏折叠按设计（最高 2 + 最弱 1）、层数不封顶文案、特质重掷排除当前、预检与提交共用编队口径、赛季 EPOCH 对齐周一并迁移、`speedFor` 注入 `now`、遗物/徽记图标、0 收益物品不出现在回收入口等。
- **性能**：`matchMedia` 缓存（tick p95 0.70 → 0.30ms）、`off` 档映射前短路；R3 判定口径改为可统计的「p50 合计 ≤0.5ms 且 max 合计 ≤2ms」（见 `docs/smoke-v3.0.md` §2 的数据与理由）。

## 三、玩法总览（并行系统线 12 条）

1. 四技能线（挖矿/熔炼/锻造/强化，各 100 级）
2. 装备与强化（10 槽、+1~+10、套装加成）
3. 词缀与重铸（9 词缀 / 4 池 / 锁定重铸 / 定向重铸券）
4. 符文双槽（12 符文，时长叠加、离线排除）
5. 传承与精通（6 线，含深造）
6. 任务（8 类日常 ×3 难度 + 周常）
7. 成就（82 项）
8. 图鉴（222 条目 / 分区门槛 / 四档称号）
9. 赛季（14 天 / 20 级 / 声望）
10. 远征与伙伴（4 路线 × 3 时长 / 6 伙伴 / 特质 / 旗帜）
11. 深渊回廊（层词条 / 连打 / 扫荡 / 结晶商店 / 称号）
12. 自动化与预设（材料自动回收 + 实例级阈值回收 + 动作预设）

**短/中/长目标**：分钟级（一轮动作、一次强化）→ 小时级（日常、远征 8h、深渊体力）→ 天级（赛季、图鉴里程碑、精通线）→ 周级以上（图鉴 100%、深渊深层、传承循环）。
**挂机纯度**：离线结算覆盖四个技能线 + 远征推进 + 图鉴/赛季计数 + 深渊回体；**唯独不自动挑战深渊**（避免不可控的随机消耗），离线文案与摘要如实标注"按期望结算"。

## 四、兼容与迁移

- `SAVE_VERSION 12 → 13`，迁移链 **1 → 13 全链可跑**（`tests/migration.test.ts` 逐版本样本 + 幂等 + 确定性）；测试文件为 v3.0 新增。
- v12 → v13 的三项迁移**均为确定性**：
  1. 图鉴：旧逗号串 → 位图（按内容表 id 顺序编位；内容表增删条目时按"已收集 id"重建，进度不丢）；
  2. 赛季：EPOCH 对齐周一后**重算 index**、按新 index 重摇任务集；`rewardedLevel` 保留（已发奖励不重复发）。
     **如实说明**：`renown` 会在迁移后由 `checkSeason` 依**任务进度**重算（任务集已换 → 通常归 0），
     因此"保留 renown"仅指"不额外惩罚"，已获取的**等级奖励**才是真正保留的部分。
     受影响窗口：旧 EPOCH（2026-01-01Z）下 index 19 的档（**2026-09-25 ~ 09-30 期间升级**）在新区间下 index 为 18。
  3. 新字段：`meta.autoRecyclePerfect` 默认 60。
- **兼容承诺续期**：v3.x 内不破坏存档结构；新增字段一律走迁移链。

## 五、已知边界（如实登记）

| 项 | 说明 |
|---|---|
| 时间前拨 | 离线回体上限提升后，单次前拨最多 **24 点体力**（≈48 结晶）；因离线回体是**时间比例**（2h 只得 4 点），前拨不产生额外收益；但"前拨 + 用光"可重复，故**每次最多 24 点**是硬边界。远征仍按 cap 窗口截断、不续派。 |
| 离线体力影响面 | 回体上限 24 意味着**每日 1~2 次上线**（间隔 ≥6h 且用光体力）的玩家日体力收入上限从 24 提到 **48**（= 回复速率理论上限 48/日）。这是"纯放置玩家不被惩罚"的设计目标，但**属于体力经济的一次显著放宽**，如实登记于此。 |
| 深渊深度 | 层数不封顶，但**层词条使终局可达层从 35 降到 34**（富矿墙）；主题每 25 层循环。 |
| 图鉴里程碑 | 四档为**分区门槛**（每个分区各自达标），实测条目数依次 **83 / 150 / 199 / 222**（线性占比 **37.4% / 67.6% / 89.6% / 100%**，由 `scripts/sim-codex.mjs` 实算）；旧制"线性 25/50/75/100%"的 50% 档曾等价于"全物品 + 7 配方"，已废弃。 |
| iOS 静音档 | WebAudio 无声属平台行为，无法绕过；设置页已写明。 |
| iOS 真机 | 仅做过模拟器级验证（安全区/图标/PWA 安装路径）；**无真机验证**，如实声明。 |
| 后台标签页 | 页面不可见时自动静音；rAF 暂停，粒子/飘字冻结（回前台继续）。 |
| 音效 | 16 条程序化合成 cue；无 BGM（范围外，见 `design-v3.0.md` §7）。 |
| 触觉反馈 | 因兼容性差不做。 |
| 排行榜 / 联机 / 交易 | 无后端，战略非目标。 |

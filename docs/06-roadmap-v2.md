## 测评评分维度（每版必测）

1. **核心循环**：动作→产出→成长的爽感与节奏
2. **深度与决策**：配装/资源分配是否有真实取舍
3. **数值曲线**：期望值/时间成本/性价比是否健康（先模拟后定档）
4. **UI 与反馈**：信息可读性、操作效率、事件提示
5. **稳定性**：存档兼容、边界情况、回归测试
6. **创新点**：本版独有的记忆点

## 硬性门禁（每版）

- typecheck / 全量测试 / build 全绿
- 存档迁移无损（含旧档回归）
- 实机验收 ≥1 条主路径 + 1 条边界路径
- 测评报告落盘（docs/review-vX.Y.md）且 Blocker 项当版清零

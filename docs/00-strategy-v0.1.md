# 战略输入：挖矿锻造放置游戏（代号 Forging）v0.1

> P10 拟制 | 2026-09-15 | 状态：待评审（R1/R2/R3）

## 1. 背景与需求（用户原始输入）

- 参考 Milky Way Idle 的核心体验：收集资源 → 加工 → 制作装备 → 强化
- 题材替换：**矿石挖掘 + 锻造各类装备物品**
- **纯前端游戏，无后端**
- 游客登录（本地存档 + 可导出导入）
- 先进行多轮评审，确定实施方案后再实施

## 2. 产品定位（一句话）

一款纯前端的矿工放置游戏：挖矿石、炼锭材、锻造装备、强化升级——在浏览器里拥有可无限挂机的成长循环。

## 3. 成功标准（可验收）

- **S1 核心循环可玩**：挖掘 → 熔炼 → 锻造 → 装备 → 强化，全链路在 30 分钟内产生正反馈
- **S2 离线收益**：关闭页面 N 小时后回来正确结算（允许保守近似，不要求逐 tick 精确）
- **S3 存档可靠**：localStorage 持久化 + 手动导出/导入 JSON；预留版本迁移机制
- **S4 内容量**：≥5 档矿石、≥2 类装备部位（武器/护甲）、工具线、强化系统
- **S5 数据驱动**：全部内容表（物品/配方/等级曲线）为 JSON，改表即可扩内容
- **S6 质量**：无崩溃；UI 响应 <50ms；离线结算 <1s；核心逻辑有单测
- **S7 体验细节**：动作队列（≥2 槽）、自动重复、数量选择（1/∞）、离线结算弹窗摘要

## 4. 做什么

- 技能线：挖掘(Mining)、熔炼(Smelting)、锻造(Forge)、强化(Enhance)
- 物品链：矿石×5档 → 锭/合金 → 工具（镐/锤等）、武器、护甲、饰品
- 数值框架：等级/经验、行动时间公式、效率、稀有掉落（借 MWI 公式结构）
- 教程引导（简化版任务链）
- 统计面板（总等级、总价值、里程碑成就）

## 5. 不做什么（减法清单，变更需评审）

- ❌ 战斗 / 迷宫 / PVP
- ❌ 多人 / 聊天 / 公会 / 排行榜（无后端）
- ❌ 玩家市场 / 交易；用商店回收 / 分解代替变现
- ❌ 复杂消耗品体系（茶/食物）——v1 砍掉
- ❌ 账号系统（游客=本地存档；导出/导入代替云同步）
- ❌ 移动端专门适配（先桌面浏览器 ≥1280px）

## 6. 关键约束

- 平台：桌面浏览器；技术栈待 R2 评审（候选：React+Vite+TS / 轻量原生）
- 无后端 ⇒ 离线收益 = 时间戳差值 + 确定性模拟；单机无对抗，不设防作弊
- 内容数据化：JSON 表 + 启动时校验
- UI 范式对齐 MWI：左导航 / 中动作面板 / 右库存装备 / 顶栏状态

## 7. 主要风险

- R1 数值曲线失衡（太快无聊 / 太慢劝退）→ 数据表可调 + 模拟脚本验证节奏
- R2 离线结算复杂（效率、队列、循环）→ 简化：只结算当前动作 + 队列按顺序模拟
- R3 存档 schema 演进破坏老档 → version 字段 + 迁移函数
- R4 前端存档可被改 → 接受（单机体验）
- R5 范围蔓延 → 以本文档「不做什么」为准

## 8. 团队编制（P9）

- **P9-A 玩法系统线**：内容表、数值、核心模拟（skills/items/recipes/offline）
  - 文件域：`src/game/**`、`data/**`
- **P9-B 表现与壳线**：UI 组件、页面框架、存档管理、导入导出、教程
  - 文件域：`src/ui/**`、`src/app/**`
- 接口契约：游戏内核（纯函数、可测、无 DOM）↔ UI（订阅状态）
- 质量门禁：核心模拟单测 + typecheck + 手动验收清单

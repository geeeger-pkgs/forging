## 4. 放行结论

- 两名评审员独立给出 **7.5 / 7.5**，均判"无 Blocker、可有条件放行"；**条件项 M1~M4 已在处置批次全部落地**，
  M5/M6 属**显式挂账**（文档已写明取舍与去处，非静默遗漏）。
- 因此 **v3.3 验收通过**。挂账项（新晋档 T2 模型、组件矩阵扩面、C4 阈值再校准、承 v3.2 的效率符文口径与
  Lv76~100 里程碑）统一登记 **v3.4**。

> 本轮最值得记住的一条：**M1（DoD 写了 40px 但没实现）**。v3.2 的教训是"测试绿 ≠ UI 可用"，

> **凡写进 DoD 的行为项，都必须有一条会红的断言**（样式类断言也是断言）。

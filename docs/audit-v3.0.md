## 二、发现并修复的真实缺陷（B1）

### B1 · 图鉴面板无限重渲染（计数不更新）——**已修复**

- **现象**：打开「图鉴」时控制台抛 `Maximum recursive updates exceeded in component <CodexPanel>`；面板分区计数（物品/配方/词缀/伙伴/遗物/矿场）**卡住不更新**。
- **根因**：v3.0 让面板在**渲染期**调用 `milestoneReached/codexGate/codexProgress`，而这些函数走的 `ensure()` **每次调用都写回 `state.codex`**（返回新对象）→ Vue 判定"组件在渲染中修改自身依赖" → 递归更新被截断，计数冻结。
- **修复**（`src/game/codex.ts`）：
  1. `ensure()` 正常路径改为**纯读**（指纹相符时直接返回原对象，零写入）；
  2. 内容表指纹移到**模块加载时算一次**（顺带消除"每次产出都重算指纹"的无谓开销）；
  3. 仅当缺字段/指纹不符时才写一次状态。
- **验证**：
  - 单元：新增「渲染期安全：进度/门槛查询必须是纯读」用例（查询前后 `state.codex` 逐字节一致）；`358 测试全绿`。
  - 实机：图鉴面板 **0 控制台错误**；真实熔炼一炉铜锭后 **已收集 16/222 → 18/222、物品 14/104 → 15/104、配方 0/92 → 1/92**（计数随玩法实时更新）。

> 这个缺陷只在**真实浏览器渲染**下暴露（node 单元测试不跑 Vue 渲染），是"逐视图实机走查"环节抓到的。

## Blocker

**BL1 · §2.3c 离线体力上限 +6：数字不实 + 上限回落删体力 + 边界未定义**
- "~50%" 实为 **37.5%**（18/48）；
- `src/game/abyss.ts:57` 的 `Math.min(DEF.staminaMax, …)` 在 bonus 结束后会**静默删除**最多 6 点存量；
- `msToNextStamina`（`abyss.ts:61-64`）在 `stamina ≥ 12` 时返回 0 → 13~17 点期间 UI 与倒计时全错；
- 触发点（≥2h 的判定位置）、持久化、跨天过期、"空摘要不弹"判定、时钟前拨收益放大 50% 均未定义。

**BL2 · §2.3a/§2.3b 层词条墙与越级挑战互相抵消 + 跳层奖励黑洞 + 可达层两套口径**
- 实算：`需求(5n+1)/需求(5n) = growth × 0.94 / 1.06 = 0.9143` → **5n+1 比 5n 便宜 8.6%**，`best+3` 可跳过富矿墙；
- 失败不消耗体力（`abyss.ts:134-137`）⇒ 越级是**零成本支配策略**（先点 +3 再退），零决策换零决策；
- `challengeAbyss` 只在 `floor > bestFloor` 发**目标层**奖励（`abyss.ts:143-146`）→ 被跳过层首通（第 35 层 120 结晶）**永不发放**；
- 顺序口径 9/24/34 与越级口径 11/26/36 两套真值未选定；§2.2"层词条会抬高可达层"与实算相反；
- 结晶 ×1.5/×0.8/×1.2 产生小数（第 1 层 9.6、第 36 层 65.6），取整规则缺失。

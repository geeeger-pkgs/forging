# Forging v1.3 测评报告（资深游戏测评者视角）

> 测评日期：2026-09-15 ｜ 版本：v1.3「饰品与荣誉」
> 测评方式（新流程）：自动化测试 72 项全绿 + 数值模拟校准 + 代码与数据走查；实机手测顺延至里程碑（v1.5 / v1.9 / v2.0）

## 一、版本内容回顾

1. **饰品系统**：项链（强化成功率 +1%~+3%，模拟定档）+ 戒指（效率 +2%~+6%），2 槽 × 5 档 = 10 件新装备 + 10 条配方（物品 58→68 / 配方 50→60）
2. **成就扩展**：29 → 40 项（槽位/任务/开箱/累计金币/强化 500 次/饰品）
3. **配套**：饰品副属性（T4/T5：项链+稀有、戒指+产量）、每日任务池新增「巧手饰匠」、物品详情浮层补属性显示
4. **存档 v4**：链式迁移（v1→v4 / v2→v4 / v3→v4）+ 拒绝未来版本

|---|---|---|
| 无（基线） | 44.1 次 | 与 v0.2 定档一致 ✅ |
| +1.0%（T1） | 41.1 | 早期小幅增益 |

## 四、发现清单与处置

### 已修复（本版内闭环）
1. **[Major] 物品详情浮层不显示属性** —— 在数值驱动游戏中属信息缺失，已补属性行（速度/效率/产量/经验/稀有/强化成功率）
2. **[Major] 饰品缺少获取引导** —— 玩家可能永远不知道项链增强化率；已加每日任务「巧手饰匠」+ 商店属性速记补充饰品说明
3. **[Minor] 生成器日志硬编码"锻造 45"**（实际 55）已改动态计算
4. **[Minor] 右栏属性行未展示"强化成功率"总数** 已补

### 观察项（延后至 v1.9 全量平衡轮）
- **W1 效率堆叠**：剑+靴+戒指+套装满配 ≈ +28.5% 期望产出，届时应与产量/稀有跨属性审计
- **W2 套装阈值**：10 槽下"≥8 件同档"更易达成，需复核是否让套装成为默认最优解（削弱配装多样性）
- **W3 饰品实机手感**：掉落展示、强化成功率变化的感知强度留待里程碑实机确认

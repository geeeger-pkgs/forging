## 3. 教训（本轮最该记住的）

- **"把被测对象钉在使结论成立的那一点上"不是证明**：V1 的 ratio=0 来自"快轮回恰好 0 点"，属自证；
  正确做法是**对策略空间扫描**（停点 + 混合），并对最优点断言。
- **v3.3 刚立的规矩又要用一次**：凡"面板/文档里的数字"必须有断言守（V4 的 +1/+4、V10 的示例数字）。
- **一个改动可能把既有差异放大成事故**（V6：两档系数从 1.5% 拉开到 94% 后，"赛季中途跨档"从不可见变成倒退）。

## 4. 放行结论

**不放行**。V1~V10 处置完成后重新复审；v3.4 版本号不发布（`package.json` 保持 3.3.0），
处置结果并入 v3.4 收口后再走 ⑥。

# Forging v1.7 测评报告（资深游戏测评者视角）

> 测评日期：2026-09-15 ｜ 版本：v1.7「自动化」
> 测评方式：自动化测试 104 项全绿 + 代码与交互走查（实机手测顺延至 v1.9 平衡轮）

## 一、版本内容回顾

1. **自动回收**：材料级白名单 + 保留数量；超出部分自动卖出换金；主循环定期清扫 + 启动时清扫（含离线产出）
2. **动作预设**：一键保存「当前动作 + 队列」；应用时逐项校验（等级/材料/队列位），非法动作跳过并提示；跨传承保留
3. **统计面板强化**：总动作数 / 传承次数 / 符文制作 等 9 项指标
4. **配套**：右栏材料行「自动·留N」状态按钮（点亮即生效）；存档 v7（v1→v7 链式迁移回归）

## 二、自动化的设计价值

| 场景 | 自动化前 | 自动化后 |
|---|---|---|
| 挂机产煤/产矿 | 库存膨胀，需手动批量回收 | 设「留 200 自动」，金币持续入账（含离线段） |
| 刷新档位循环 | 手动重设 3~4 个动作 | 「应用预设」一键回到生产序列 |
| 传承后重启 | 重配队列 | 预设跨传承保留，登录即应用 |
| 离线时段 | 产出全量囤积 | 清扫发生在离线结算之后 → 离线产出也被自动变现 ✅ |

**设计亮点**：清扫顺序（离线结算 → 任务基线 → 自动回收）避免了"离线收益被误计入当日任务"的冲突，与 v1.2 评审的基线隔离规则一致。

## 四、发现清单与处置

### 已修复（本版内闭环）
1. **[Major] 类型契约遗漏**：新增命令/事件未同步 Command/GameEvent 联合类型——`vue-tsc` 在第一时间全面拦截（14 处报错），补齐后全绿。防线有效性再次验证

### 观察项（v1.9 平衡轮 / v1.8 顺手优化）
- **W1 自动回收与任务冲突**：如"开箱任务"需要小箱、强化任务需要锭——玩家若误开自动可能饿死任务链。建议 v1.8 在设置页标注典型保留建议（而不做强制约束）
- **W2 金币产出加速**：自动回收让"累计金币"成就与金币任务更容易完成——可接受（金币 sink 仍只有队列位/重掷），v1.9 审计
- **W3 预设置信度**：应用预设时若关键材料不足会静默跳过（有提示）——v1.9 考虑"预检面板"（应用前显示缺失清单）

## 五、结论

**通过（8.3/10）。** v1.7 把"挂机深度"提升到与"手动深度"同等重要的位置：游戏现在同时适合"每天点几下"与"纯挂机"两类玩家。
迭代方向确认：进入 **v1.8「全平台」**（PWA 可安装 + 响应式布局，移动端可用）。

## 关键实机记录

### S2 离线结算（20 分钟回拨）
- 完成动作：铜矿脉 × **201**（1200s ÷ 6s = 200 + 余量轮）
- 获得物品：铜矿石 × **402**（期望值 2/轮，精确命中）、精华 × 3（0.017×201=3.417，整数发放 + 小数结转）
- 技能经验：挖掘 +1005；升级：Lv6 → Lv10（连续 5 次升级事件）
- 附带验证：Lv10 后铁矿脉自动解锁（锁定/解锁状态流转正确）

### 存档持久化
- 刷新恢复：运行中动作（含剩余进度）、材料、等级、教程进度、队列位、装备实例全部无损
- 自动保存：5s 周期 + 每次操作 + beforeunload；双槽备份（主槽损坏自动回退）

### 核心循环（用户实机）
- 新档 → 挖矿（含 1.7% 精华稀有掉落触发）→ 熔炼 → 锻造铜镐 → 教程链推进，全程无卡点
- 队列扩容快捷入口（动作对话框 + 商店面板）与金币闭环（回收 → 300/1200 队列位）可用

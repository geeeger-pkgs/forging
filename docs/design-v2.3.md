# Forging v2.3 设计文档 ·「图鉴与赛季」

> 阶段：① 创意 → ② 计划（本文档）→ ③ 评审（独立评审仲裁）→ ④ 开发 → ⑤ 测试 → ⑥ 测评
> 上游：docs/08-roadmap-v3.md（v2.3 = 长线目标：收集与轮换驱动）
> 依赖：v2.2 已发布（远征徽记 / 伙伴 / 遗物 / 存档 v9）；本版存档 **v10**
> 原则：**先模拟后定档** —— 本文档所有数值均取自 `scripts/sim-season.mjs` 的实际输出（§3.1）

## 1. 动机（创意）

v2.2 之后游戏有五条并行系统，但缺两样东西：

1. **没有"收集"的终点**：物品/配方/词缀/伙伴/遗物散落在各系统里，玩家看不到"我完成了多少"，也没有完成度奖励。
2. **没有周期性目标**：日常/周常是短周期，传承/深渊（v2.4）是超长周期，中间缺一层"赛季"——14 天一个循环，每季换任务，给中后期玩家稳定的"这段日子有事干"。

v2.3 落点：**给所有既有内容加一层"目录"，再给中后期玩家一个周期性的追逐框架**。

一句话：**图鉴回答"我收集了多少"，赛季回答"这两周我在追什么"。**

## 2. 系统设计（计划）

### 2.1 图鉴（Codex）

**6 个分区，共 222 条目**（脚本清点，遗物单列避免与物品重复计数）：

| 分区 | 条目数 | 解锁条件（"发现"定义） |
|---|---|---|
| 物品（材料/装备/符文） | 107 | 曾经持有过（材料数 > 0 或存在该装备实例） |
| 配方 | 92 | 曾经制作成功过 1 次 |
| 词缀 | 9 | 曾经在某件装备上出现过（造装或重铸） |
| 伙伴 | 6 | 曾经招募到 |
| 遗物 | 3 | 曾经获得过 |
| 矿场 | 8 | 曾经开采过 1 次 |

- **持久化**：`meta.codex = { items: string[], recipes: string[], affixes: string[], ores: string[] }`（伙伴/遗物分别由 `companions` 与材料表推导，不重复存储）。
- **扫描式更新**：由 `checkCodex(state)` 幂等扫描（与 `checkAchievements` 同模式，主循环与命令后调用），不在低层发放函数里埋点。
- **规模**：222 条短 id ≈ 3KB 存档增量（可接受；v9 存档约 10~20KB）。

**里程碑（每 25% 一档，达到即自动发奖 + 给赛季声望）**

| 里程碑 | 条目数 | 声望 | 奖励 |
|---|---|---|---|
| 25% | 56 | 4 | 1,250 金 + 精华 ×10 |
| 50% | 111 | 8 | 5,000 金 + 精华 ×20 + 徽记 ×3 |
| 75% | 167 | 12 | 11,250 金 + 精华 ×30 + 徽记 ×3 |
| 100% | 222 | 16 | 20,000 金 + 精华 ×40 + 徽记 ×10 |

### 2.2 赛季（Season）

- **周期**：14 天（`seasonIndex = floor((now − EPOCH) / 14d)`，按本地时间派生；与日常任务同样"前向轮换"，回拨时钟无效）。
- **任务**：3 条固定槽位，从 6 条模板池按赛季键**确定性**抽取（同赛季内所有玩家一致、可复现；`pickSeasonTasks(key)`）；同一赛季内模板不重复。
- **三档目标 + 声望**：

| 档位 | 声望 | 挖掘 | 熔炼或锻造 | 累计金币 | 强化尝试 | 完成远征 | 重铸词缀 |
|---|---|---|---|---|---|---|---|
| 铜 | 10 | 20,000 | 10,000 | 1,200,000 | 600 | 20 | 30 |
| 银 | 20 | 45,000 | 22,000 | 2,600,000 | 1,300 | 40 | 65 |
| 金 | 40 | 72,000 | 36,000 | 4,000,000 | 2,000 | 60 | 100 |

- **声望等级**：1~20 级，每级 6 声望（满级 120 = 3 条任务全金）；**达到即自动发奖**（无领取步骤 → 赛季重置不产生"忘领奖励"挫败）。
- **等级奖励**：`金 = 500 + 250×等级`、`精华 = 1 + ⌊等级/4⌋`，每 5 级给徽记 ×2，满级给徽记 ×10（合计 16）。
- **进度口径**：与日常/周常共用计数器（`totalMines/totalCrafts/totalGoldEarned/totalEnhances/totalExpeditions/totalReforges`）+ 赛季基线快照（同 `TaskSlot.base` 的隔离写法），**离线期间的产出照常计入**（计数器单调递增，无需额外离线规则）。
- **解锁门槛**：总等级 ≥ 60（避免新玩家被 4 位数目标打击）。

### 2.3 数值定位（§3.1 的结论摘要）

- 三条任务**并行**推进：全金档由最慢一条决定 → **中期 10.0 天 / 终局 5.4 天**（14 天窗口，中期留 4 天缓冲）。
- 档位梯度有效：铜档中期最快 1.0 天 → 休闲玩家也能拿到铜/银档声望。
- **赛季不发大量金币**（满级总奖励 ≈ 66,675 金等价 ≈ 终局 0.9 小时产出）→ **不构成通胀**；真正的奖励是**稀缺的远征徽记**（16/赛季 ≈ 远征单赛季产出的 15.2%）→ 加速但不替代远征。
- 图鉴里程碑给 40 声望（占赛季总需求 33.3%）→ 收集度与赛季自然耦合，但不喧宾夺主。

### 2.5 UI

1. 「📖 图鉴」页签（置于「远征」下方）：上半部 6 个分区卡片（图标 + 完成度 + 里程碑），下半部赛季面板。
2. 分区展开可看未解锁条目（灰色 + 获取提示：如"需要 T5 熔炼"），避免"我缺什么"不可知。
3. 赛季面板：剩余天数、声望等级与进度条、3 条任务（三档目标 + 当前进度 + 完成标记）。
4. 窄屏（≤900px）：分区卡片单列，赛季任务纵向堆叠。

### 3.1 模拟结论（脚本实测）

| 项 | 结果 | 判定 |
|---|---|---|
| 图鉴规模 | 222 条（物品 107 / 配方 92 / 词缀 9 / 伙伴 6 / 遗物 3 / 矿场 8） | 规模足够撑一个版本 ✅ |
| 里程碑条目门槛 | 56 / 111 / 167 / 222 | 梯度均匀 ✅ |
| 赛季满级需求 | 120 声望（3 条任务全金），20 级 × 6 声望 | — |
| 全金耗时（中期） | **10.0 天**（最慢一条 = 累计金币 4.0M） | 落在 14 天窗口内（留 4 天缓冲）✅ |
| 全金耗时（终局） | 5.4 天 | 终局玩家有富余，可带新玩家/做图鉴 ✅ |
| 档位梯度 | 铜档中期最快 1.0 天 | 休闲玩家可拿铜/银档 ✅ |
| 满级奖励价值 | ≈ 66,675 金等价（终局 0.9 小时产出）+ 徽记 ×16 | 不构成通胀 ✅ |
| 徽记注入占比 | 16 / 赛季远征产出 105 ≈ 15.2% | 加速但不替代远征 ✅ |
| 图鉴声望占比 | 40 / 120 = 33.3% | 收集与赛季耦合，不喧宾夺主 ✅ |

## 6. 风险与对策

| 风险 | 对策 / 现状 |
|---|---|
| 赛季奖励造成通胀 | 只发小额金币，主体奖励是稀缺徽记（占远征产出 15.2%）✅ |
| 忘领奖励的挫败 | 达到等级**即时自动发放**，无领取步骤 ✅ |
| 赛季目标对休闲玩家过高 | 三档梯度（铜/银/金）+ 铜档中期 1.0 天可达 ✅ |
| 图鉴成为"必须全收集"的负担 | 里程碑只到 100%，且奖励为锦上添花；不做"缺一不可"的强绑定 ✅ |
| 老档无法回溯配方/词缀 | 如实登记为设计取舍；物品/伙伴/遗物可回溯 ✅ |
| 页签过多（第 7 个） | 赛季并入图鉴页，只加 1 个页签 ✅ |
| 存档膨胀（222 条 id） | ≈3KB；必要时改用位图（v3.0 审计再评估） |

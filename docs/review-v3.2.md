# Forging v3.2「界面打磨」资深玩家评审（两名独立评审员）

> 阶段：⑥ 资深游戏玩家评审。对象：v3.2.0（提交 `1ebeef4` 之前的工作树 + `1ebeef4` 的 DoD 修正）。
> 方法：两名评审员**独立**评估（互不可见对方结论），各自可读代码/文档/截图、可跑只读命令；
> 评审素材：`docs/design-v3.2.md`（设计与 DoD）、`docs/smoke-v3.2.md`（实机证据）、
> `docs/v32-mobile-default.png` / `-drawer.png` / `-rightpanel.png` / `v32-desktop.png`（真实浏览器截图）、
> 上版基线 `docs/review-v3.0-two-players.md` / `-hardcore.md` / `-ux.md`。
> 评审员 A：硬核放置玩家（信息密度 / 操作效率 / 数值可读性 / 文档-实现一致性）。
> 评审员 B：新手 + 移动端体验（第一屏可懂性 / 触控 / 误操作 / 文案）。

## 1. 结论

| 评审员 | 分数 | 一句话结论 |
|---|---|---|
| A 硬核 | **5.5 / 10** | 方向对、约一半改动真把操作路径/可读性往硬核想要的方向推了，但**一条核心操作（卸下）被这版改到 UI 不可达**，且 B3/B4/D2 三项属"文档说已落地、实际没落地或只落一半" |
| B 新手/移动 | **6.5 / 10** | 布局层硬伤（横向溢出、工具平铺吃首屏）真修好了、首屏也能看懂，但"能看见"与"点得到"只做了一半：右栏入口首屏完全不存在、按钮普遍 20 多像素高、点槽位后承诺的「卸下」实际不存在 |

**结论**：不通过（B 判"不该按打磨版放过"，A 判"不能按已验收放行"）。两条独立评审在
**卸下不可达**与**右栏 Tab 首屏不可达**上互相印证，属高置信度缺陷。

## 3. DoD 复核意见（评审员对 `design-v3.2.md` §3 的判断）

- **"B1~B7/C1~C3 全部落地"当时不成立**：B2（卸下）未落到可达 UI、B3 死选择器、B4 只有 helper 没有集成、B6 部分未兑现、C3 部分残留 —— 该条属"测试绿代替逐条人眼验收"。**处置**：本轮修完上述项后该条才成立；DoD 文本已改为分条列证据。
- **"格式统一"原为自我背书**（只测了尺子没量身高）：本轮迁移调用点 + 加守卫后成立。
- **"键盘可操作（只测到 Space）"**：评审员 B 认为登记诚实；评审员 A 认为"Playwright Enter 不触发原生 button click"更像 iframe/焦点注入问题而非浏览器语义。**处置**：本轮用 `setViewportSize` 直连视口后**再次**用两条注入路径（Playwright `press` 与 CUA 原始按键）复测 Enter，仍不触发；两控件均为原生 `<button>`、无 `tabindex=-1`、无 `preventDefault`，故维持"Space 路径有证据、Enter 路径本环境无证据"的登记，并注明真实浏览器按平台语义应可用。
- **"test/typecheck/build 全绿"**：证据充分，但两名评审都指出**全绿 ≠ 本版 UI 可用**（无组件测试）。已登记为 v3.3 基础设施项。

## 4. 本轮修复后复验（实机 375×720，`setViewportSize` 直连视口）

> 说明：v3.0 期 IAB 不支持视口调节（故当时用同源 iframe 注入）；本机 IAB 现已支持
> `setViewportSize`，本轮全部改用它，结论与 iframe 法一致。

| 项 | 实测 |
|---|---|
| 底栏首屏可见 | 未滚动时 `top=667 / bottom=720`（视口 720）✅ |
| 抽屉默认收起 | `#nav-tools` display:none、`aria-expanded=false` ✅ |
| 抽屉选中后收起 | 点「更多」展开 → 点「图鉴」→ 视图切到"图鉴与赛季"且抽屉收起 ✅ |
| 卸下可达 | 点槽位 → 弹窗 footer `卸下/关闭/⚒重铸` → 点击后槽位「空」且装备留在行囊 ✅ |
| 材料菜单 | 只在被点行内（1 个实例，`gapPx=2`），`应用` 在无输入时置灰 ✅ |
| 触控尺寸 | `.rtab` 实测高度 40px ✅ |
| 门禁 | 414 测试 / 24 文件全绿；typecheck 无错；build gzip 106.08KB（≤110KB 修订预算）✅ |

> 关闭该设置后复验，装备正常留在行囊。这也提示 v3.3 可考虑"卸下瞬间被自动回收"的提示文案。

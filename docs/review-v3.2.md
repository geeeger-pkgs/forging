## 3. DoD 复核意见（评审员对 `design-v3.2.md` §3 的判断）

- **"B1~B7/C1~C3 全部落地"当时不成立**：B2（卸下）未落到可达 UI、B3 死选择器、B4 只有 helper 没有集成、B6 部分未兑现、C3 部分残留 —— 该条属"测试绿代替逐条人眼验收"。**处置**：本轮修完上述项后该条才成立；DoD 文本已改为分条列证据。
- **"格式统一"原为自我背书**（只测了尺子没量身高）：本轮迁移调用点 + 加守卫后成立。
- **"键盘可操作（只测到 Space）"**：评审员 B 认为登记诚实；评审员 A 认为"Playwright Enter 不触发原生 button click"更像 iframe/焦点注入问题而非浏览器语义。**处置**：本轮用 `setViewportSize` 直连视口后**再次**用两条注入路径（Playwright `press` 与 CUA 原始按键）复测 Enter，仍不触发；两控件均为原生 `<button>`、无 `tabindex=-1`、无 `preventDefault`，故维持"Space 路径有证据、Enter 路径本环境无证据"的登记，并注明真实浏览器按平台语义应可用。
- **"test/typecheck/build 全绿"**：证据充分，但两名评审都指出**全绿 ≠ 本版 UI 可用**（无组件测试）。已登记为 v3.3 基础设施项。

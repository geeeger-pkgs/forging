# Forging v2.4 设计文档 ·「深渊回廊」

> 阶段：① 创意 → ② 计划（本文档）→ ③ 评审（独立评审仲裁）→ ④ 开发 → ⑤ 测试 → ⑥ 测评
> 上游：docs/08-roadmap-v3.md（v2.4 = 终局：给满配玩家目标）
> 依赖：v2.3 已发布（图鉴/赛季/存档 v10）；本版存档 **v11**
> 原则：**先模拟后定档** —— 全部数值取自 `scripts/sim-abyss.mjs` 输出，并落 `docs/sim-abyss-output.json` 供测试机器校验

## 1. 动机（创意）

v2.1~v2.3 把「产出」「并行线」「长线目标」补齐了，但**没有任何内容检验 build 本身**：玩家堆到 +10 满配、词缀洗满、精通点满之后，唯一的反馈是"数字变大了"。同时 v2.2 测评留下一个明确建议（"钱/石够也摇不到想要的词缀 id"）、v2.3 图鉴的 100% 卡在 3 件遗物上。

v2.4 落点：**一条即时判定的层数挑战回廊**。
- **深渊战力 = 六项属性的加权和**（公式对玩家明示）→ 深度由 build 的**广度**决定，逼玩家在速度/效率/产量/稀有/经验/强化率之间做取舍。
- **门槛逐层递增**（0.45 × 1.086^(层−1)），主题每 5 层一换（叙事层，不改数值）。
- **深渊结晶**（不可回收、不可换金）→ 深渊商店卖**稀缺功能**：定向重铸券、遗物兑换、永久速度、称号。

一句话：**前面几个版本回答"怎么变强"，深渊回答"你到底有多强"。**

## 2. 系统设计（计划）

### 2.1 深渊战力（build 检验口径）

```
深渊战力 = 1.0×速度 + 1.5×效率 + 1.0×产量 + 0.7×稀有 + 0.5×经验 + 2.0×强化成功率
```

- 六项均取**当前装备/词缀/符文/精通/永久加成的实时合计**（即 `aggregateEquipment` + buff + perk + 本版永久加成）。
- 权重明示在面板上（含每项贡献值），玩家可自行推算"还差多少"。
- **为什么不是单项硬门槛**（v2.4 初版方案的实测教训）：按单项门槛时，实测前期 1 层 / 中期 2 层 / 终局 2 层——因为每个人的最弱项（产量 0.27、强化率 0.05）几乎不随 build 提升，全员被同一项卡死。改加权和后前期 9 / 中期 24 / 终局 35 层。

### 2.2 层数与门槛

| 层 | 主题 | 门槛 | 层 | 主题 | 门槛 |
|---|---|---|---|---|---|
| 1 | 矿脉裂隙 | 0.450 | 25 | 虚空之喉 | 3.259 |
| 5 | 矿脉裂隙 | 0.626 | 30 | 矿脉裂隙 | 4.924 |
| 10 | 熔岩回廊 | 0.946 | 35 | 熔岩回廊 | 7.437 |
| 15 | 符文甬道 | 1.428 | 40 | 符文甬道 | 11.235 |
| 20 | 无光深渊 | 2.158 | | | |

- 门槛 = `0.45 × 1.086^(层−1)`；**主题仅叙事**（每 5 层一换），不改数值。
- 层数无上限；深度由 build 决定，后续版本追加成长轴时深度自然延伸（曲线不用改）。

### 2.3 体力与挑战

- **体力**：上限 **12**，恢复 **1 点 / 10 分钟**（6/时）。
- **挑战下一层**（消耗 1 体力）：`战力 ≥ req(bestFloor+1)` → 通关并记录新最高层；否则提示"还差 X 战力"（体力照常消耗，不退款）。
- **扫荡回廊**（消耗 1 体力）：仅当 `bestFloor ≥ 1`，获得 `1 + ⌊bestFloor/10⌋` 结晶（不进层）。
- 每日可挑战层数：常驻在线 144 / 每日 3 次上线 36 / 2 次 24 / 1 次 12（**上限 12 让放置玩家也能一次连打**）。

### 2.4 奖励与商店

**通关奖励（深渊结晶，首次通关）**：`10 + 2×层`（第 1 层 12、第 35 层 80）。

| 商店项 | 价格 | 上限 | 效果 |
|---|---|---|---|
| 定向重铸券 | 120 | 4 张 | 重铸时**指定一条词缀 id 保底出现**（回应 v2.2 测评建议） |
| 遗物兑换 | 240 | 3 件 | 每件遗物各可兑换 1 次（补齐 v2.3 图鉴 100% 的最后一块） |
| 永久速度 | 200/级 | 5 级 | 每级 **+1% 速度**（永久，计入堆叠审计） |
| 称号「深渊行者」 | 300 | 1 | 展示用（顶栏显示） |

- 商店全清 ≈ **2,500 结晶**；中期首通 840（34%）、终局首通 1,610（64%），其余靠扫荡（终局 4/次 → 约 19 天）→ 长线追逐 ✅
- 结晶**不可回收、不可换金**（不进 `totalValue`、不参与回收）→ 不产生金币通胀。

### 2.5 状态硬规则（离线/幂等/时钟，v2.3 教训：先定语义再定数值）

1. **体力按真实时间恢复、离线照常**：`stamina = min(12, stamina + ⌊(now − staminaAt)/600000⌋)`，同时 `staminaAt += 获得的点数×600000`（**单调守卫**：`now < staminaAt` 时不变 → 回拨时钟无法刷体力）。
2. **离线不自动挑战**：回廊是主动选择，离线只回体力；离线摘要**不出现**深渊条目（无离线收益即无提示需要）。
3. **通关幂等**：`bestFloor` 单调递增；首通奖励只在 `floor > bestFloor` 时发放一次；重复挑战同一层永远走"扫荡"路径。
4. **扫荡幂等**：每次扫荡消耗 1 体力、发一次结晶，无可重复领取的"已完成状态"（不像远征需要领取）。
5. **商店购买一次生效**：`purchased: string[]`（`reroll_ticket` 可累计 4 次，其余各 1 次）；再次购买已满项 → `blocked`。
6. **体力不溢出**：恢复受上限约束；挑战/扫荡时若 `stamina < 1` → `blocked`（提示恢复时间）。
7. **重铸券语义**：券在 `reforge` 命令里以 `ticketAffixId` 传入；该 id 必须属于该装备原型的词缀池且**未与锁定 id 冲突**，否则 `blocked` 且不消耗券；成功时该 id 必出现在结果中（其余槽位按原规则抽取）。

## 6. 风险与对策

| 风险 | 对策 / 现状 |
|---|---|
| 门槛曲线把所有人卡在同一层（初版失败模式） | 已用**搜索**定档 + 加权和口径；三档画像实测 9/24/35 ✅ |
| 成为第三条"必须每天上线"的压力线 | 上限 12 让 1 次上线也能连打；无每日任务/无排名；扫荡可快速消耗体力 ✅ |
| 永久速度破坏堆叠平衡 | 仅 +5% 上限，计入 `sim-audit` 堆叠审计（满配 +304% → +309%，远不触底）✅ |
| 定向重铸券让词缀追满变廉价 | 每张 120 结晶、上限 4 张；券只保底"出现某条 id"，数值仍需重铸 ✅ |
| 与图鉴/远征的遗物来源冲突 | 商店兑换是**补充**来源（各 1 次），远征稀有掉落仍是主力 ✅ |
| 页签过多（第 8 个工具按钮） | `.tools` 已 flex-wrap（v2.2 修复）；窄屏实测 |
| 老档迁移获得满体力 | 迁移把 `staminaAt` 设为当前时刻 → 从 0 开始恢复 ✅ |

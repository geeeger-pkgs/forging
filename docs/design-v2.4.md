## 1. 动机（创意）

v2.1~v2.3 补齐了产出、并行线与长线目标，但**没有任何内容检验 build 本身**；同时 v2.2 测评留下明确建议（"钱/石够也摇不到想要的词缀 id"），v2.3 图鉴 100% 卡在 3 件遗物上。

v2.4 落点：**即时判定的层数挑战回廊** + **结晶商店**。

一句话：**前面几个版本回答"怎么变强"，深渊回答"你到底有多强"。**

## 2. 系统设计（计划）

### 2.1 深渊战力（口径硬定义，评审 B3）

```
深渊战力 = 1.0×速度 + 1.5×效率 + 1.0×产量 + 0.7×稀有 + 0.5×经验 + 2.0×强化率
```

**六项的取值口径逐项写死**（与 `settle.ts` 的实现一致，禁止各写一套）：

| 项 | 口径 |
|---|---|
| 速度 | **采矿速度** = `agg.allSpeed + agg.toolSpeed.mining + buff.speed + perk.speed + abyss.permanentSpeed`（取采矿一项，不用平均/求和） |
| 效率 | `agg.efficiency + buff.efficiency + perk.efficiency` |
| 产量 | `agg.quantity`（**无** buff/perk，与实现一致） |
| 稀有 | `agg.rareFind + buff.rareFind + perk.rareFind` |
| 经验 | `agg.wisdom + perk.wisdom`（**无** wisdom 符文，与实现一致） |
| 强化率 | `agg.enhanceRate + buff.enhanceRate`（**无** perk，与实现一致） |

- 实现为**纯函数** `abyssScore(state, now)`（`now` 由命令层注入 → 符文增益可复现，测试不依赖 `Date.now()`）。
- 权重与六项贡献值在面板上明示，玩家可自行推算差额。
- **永久速度（深渊商店）的落点唯一**：写入 `meta.abyss.permanentSpeed`，由 `aggregateEquipment` 汇总进 `allSpeed`；`speedFor` 与 `abyssScore` 都从该汇总读取 → 战力与动作时长**天然同源**（无"两处各加一次"的歧义；复审 B3 残留处置）。

### 2.2 层数与门槛

- 门槛 = `base × growth^(层−1)`，主题每 5 层一换（**仅叙事，不改数值**）。
- **定档方式（如实标注）**：先定「终局满配 ≈ 35 层」，再**反解** `base = 终局战力 / growth^34`，最后在 ±3% 的 base 邻域**搜索验证**（脚本 B 段，可复跑）：**34 个取值满足三档目标带** → 曲线稳健。
- 定档参数（脚本输出）：**base 2.764，growth 1.031**（由"三档战力差 2.26×"反推：`2.26^(1/26 层) ≈ 1.031`）。

| 层 | 门槛 | 层 | 门槛 |
|---|---|---|---|
| 1 | 2.764 | 24 | 5.578 |
| 9 | 3.529 | 30 | 6.699 |
| 15 | 4.238 | 35 | 7.804 |
| — | — | 40 | 9.091 |

> 上表逐格取自 `docs/sim-abyss-output.json` 的 `reqAt`（测试 A12 逐字段校验）。
>
> **为什么不能用陡曲线**：三档理论满配的战力分别是 3.67 / 5.96 / 7.81（差 2.26×）。若用 8~11%/层的陡曲线，三档只能落在 5~10 层内，「层数」就失去意义。真实约束是**当前版本的可达属性区间较窄**（且其中相当一部分来自不随档位变化的符文/精通）——该发现记入 §6 风险与 v3.0 输入。

### 2.3 体力与挑战

- **体力**：上限 **12**，恢复 **1 点 / 30 分钟**（2/时 = 48/日理论）。
- **恢复规则（实现级伪码，评审 B4）**：

```ts
function regenStamina(state, now) {
  if (now <= state.staminaAt) return               // 回拨/异常：不动
  const ticks = Math.floor((now - state.staminaAt) / REGEN_MS)
  if (ticks <= 0) return
  state.staminaAt += ticks * REGEN_MS              // 按 raw tick 推进（余数保留）
  state.stamina = Math.min(CAP, state.stamina + ticks) // **超额丢弃**（满体力期间的时间不积压）
}
```

- 由此：离线 8h 回线最多打 **12 次**（不是 12+16=28，也不是 60）——A5 用例覆盖该反例。
- **挑战下一层**（1 体力）：仅当 `战力 ≥ req(bestFloor+1)` 时**允许发起**；不满足 → `blocked`（**不消耗体力**）并显示"还差 X 战力"。
  > 复审 ① 处置：原稿 §2.3（消耗体力无进展）与 §2.7（按钮禁用）矛盾 → 统一为**不满足即不允许发起**（对玩家更友好，也消除"浪费体力"的争议路径）。
- **扫荡**（1 体力）：仅当 `bestFloor ≥ 1`；获得 `1 + ⌊bestFloor/20⌋` 结晶（不进层）。
- 每次挑战/扫荡消耗 1 点，故**每日最多 12~48 次**（1 次上线 12 / 每日 2 次 24 / 常驻 48）。

### 2.4 奖励与商店（评审 B5：永续出口）

**首通奖励**：`10 + 2×层` 结晶（第 1 层 12、第 35 层 80）。结晶**不可回收、不可换金**。

| 商店项 | 首价 | 价格递增 | 上限 | 效果 |
|---|---|---|---|---|
| 定向重铸券 | 100 | **×1.3/次** | 12 张 | 重铸时指定一条词缀 id 保底出现（回应 v2.2 测评建议） |
| 永久速度 | 150 | **×1.3/级** | 8 级 | 每级 +1% 速度（计入堆叠审计） |
| 遗物兑换 | 200 | — | 3 件 | 每件遗物各 1 次（补齐 v2.3 图鉴 100%） |
| 称号「深渊行者」 | 200 | — | 1 | 展示用（顶栏显示） |

- **首轮目标 = 2,776 结晶**（4 券 + 3 遗物 + 5 级永久 + 称号）；终局首通 1,610 覆盖 **58%**，缺口 1,166 ÷ 扫荡 2/次 = **583 次** → 常驻在线 **12.1 天** / 每日 2 次上线 **24.3 天** ✅
- **可重复 sink（有明确上限）**：券（上限 12）与永久速度（上限 8 级）可重复购买、价格 ×1.3 递增（第 12 张券 1,792、第 8 级永久 941）；**全部买满 ≈ 11,812 结晶**。

- 中期（25 层）首通 900 → 覆盖首轮 8%（在阶梯上，不是毕业）✅

### 2.5 状态硬规则

1. **体力按真实时间恢复、离线照常、溢出丢弃**（§2.3 伪码）；**单调守卫** `now ≤ staminaAt` 时不变。
2. **离线不自动挑战**；离线摘要**不出现**深渊条目（无离线收益 → 无需提示）。
3. **通关幂等**：`bestFloor` 单调递增；首通奖励仅在 `floor > bestFloor` 时发一次；重复挑战同层只能走扫荡。
4. **扫荡幂等**：一次扫荡 = 1 体力 + 一次结晶，无可重复领取的挂起状态。
5. **购买**：`purchased` 记录每项已购次数；超过 `max` 或结晶不足 → `blocked`；价格 = `首价 × 1.3^已购次数`（整数四舍五入）。
6. **体力不足**：`stamina < 1` → `blocked`（提示恢复倒计时）。
7. **定向重铸券语义（评审 B3/B5 补充，5 条契约）**：
   1. `Command.reforge` 增可选 `ticketAffixId`；仅在**有券且券数 ≥1** 时允许传入。
   2. 该 id 必须属于**被重铸装备原型的词缀池**，且**不与 `locks` 对应的词缀 id 重复**；否则 `blocked` 且**不消耗券**。
   3. 池内剩余条数（池 − 锁定 id − 券指定 id）必须 ≥ 需要抽取的条数；否则 `blocked` 且不消耗券。
   4. 成功时**该 id 必出现在结果中**（占一个未锁定槽位，数值按正常 roll 抽取）；其余未锁定槽位从「池 − 锁定 id − 券 id」抽取。
   5. 券在**成功路径**上恰好消耗 1 张；失败/阻塞路径不消耗。
   > **边界反例（必测）**：① 券 id 与锁定 id 相同 → blocked 不耗券；② T7 四槽全锁 → 无可抽取槽位 → blocked；③ 券 id 不在该装备原型池（如给镐指定 `midas`）→ blocked。

## 6. 风险与对策

| 风险 | 对策 / 现状 |
|---|---|
| 曲线把所有人卡在同一层（初版失败模式） | 已用"反解 + 邻域搜索"定档，三档实测 8/25/35；±30% 不反转 ✅ |
| **当前版本属性区间太窄**（三档只差 2.04×） | 曲线压到 2.75%/层以适配现状；**v3.0 若追加成长轴，深度自然延伸**（记入 v3.0 输入）✅ |

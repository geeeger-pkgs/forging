# Forging v3.2 设计文档 ·「UI/UX 集中优化」

> 来源：两位玩家测评中**全部未落地**的界面/交互项（`docs/review-v3.0-ux.md` 为主，`-hardcore.md` 补充）
> 用户指令：v3.2 集中做 UI/UX 的优化
> 原则：本版**不改数值**（唯一例外见 §4 的"顺带卫生项"，且都有测试守护）；一切改动都要能在窄屏与键盘下验证

## 1. 范围（四组）

### A 移动端 / 窄屏（测评 B-10、F）
| # | 问题 | 方案 |
|---|---|---|
| A1 | 导航把 4 技能 + 8 工具 + 静音 + 教程卡全部平铺，390px 下吃掉半个首屏 | 工具区收进**「更多」抽屉**（点击展开/收起，带 aria-expanded）；技能区与静音常驻 |
| A2 | 右栏（装备/资源/行囊）永远沉在整页最底部 | 窄屏下改为**底部悬浮 Tab**（装备/资源/行囊三键切换，默认收起；点击展开为面板） |
| A3 | 弹窗长内容时主按钮可能滚出屏 | 已做（v3.1 footer 吸底）→ 本版补：**深渊权重行折叠时给"已折叠 N 项"提示** |
| A4 | 顶栏在窄屏占位大 | 窄屏隐藏"总价值"与"总等级"，保留金币/动作/停止 |

### B 信息层级与可读性（测评 B-A/B）
| # | 问题 | 方案 |
|---|---|---|
| B1 | 材料行 4 个回收按钮 + 系统 `prompt` 设保留量 | 回收收进 **「…」菜单**（回收1/×10/全部/自动）；保留量改**内联数字输入** |
| B2 | 每个槽位常驻「卸下」按钮 ×10 | 移入**装备详情弹窗**（点击槽位打开），槽位行只留名称 |
| B3 | 装备总加成是 11px 灰字三行 | 提到 12px，并按**当前视图**高亮相关项（挖掘页亮挖速/产量…） |
| B4 | 时间/百分比单位混用（8h / 4.0 小时 / 14 分 33 秒 / 74% / 8.1%） | 统一：**时长**用 `Xs`（<60s）/ `Xm Ys`（<60m）/ `Xh Ym`；**百分比**一律一位小数 |
| B5 | 顶栏「停止」用危险色、视觉权重最高 | 降为描边按钮（hover 才显红） |
| B6 | 成就 82 项平铺、无进度 | 按"接近完成度"排序 + 每项显示 `当前/目标` |
| B7 | 强化列表平铺、找可强化件费眼 | **未满级优先** + 显示"材料够 N 次" |

### C 交互细节
| # | 问题 | 方案 |
|---|---|---|
| C1 | 键盘 Tab 焦点不可见 | 全局 `:focus-visible` 描边样式 |
| C2 | 图鉴分区要点开才知道差什么 | 默认展开**进度最低**的分区；分区行显示"还差 N 条" |
| C3 | 空态文案不统一（"暂无"/"暂无预设。"/"无所事事……"） | 统一为「暂无 X」句式 + 一句下一步提示 |

### D 顺带卫生项（不影响数值）
| # | 项 | 方案 |
|---|---|---|
| D1 | `acceptTutorial` 是空操作死命令 | 删除命令与联合成员（测试同步） |
| D2 | `settle.ts` 用 `Date.now()` 取符文增益 | 透传 `simulate` 的 `now`（与 v3.0 C12 同做法） |

## 2. 明确不做（记入 v3.3）
- 效率符文在线口径（v2.1 登记的既有取舍，改动要重跑经济审计）
- 赛季目标动态缩放（数值改动）
- 行囊/动作预设的拖拽排序、图鉴搜索全文检索

## 3. 验收标准（DoD）
- [ ] 390/375px：无横向溢出；工具抽屉可开合；右栏 Tab 可切换且默认不遮挡主内容
- [ ] 键盘：Tab 可见焦点；工具抽屉与右栏 Tab 可键盘操作（aria-expanded / aria-selected）
- [ ] B1~B7/C1~C3 全部落地，且**没有任何系统 prompt/confirm 用于日常操作**（确认框仅保留破坏性操作）
- [ ] 时长/百分比格式统一（新增 `fmtDur`/`fmtPct` 并在测试中断言边界：59s/60s/60m/1h）
- [ ] `npm test` 全绿（≥390）｜typecheck｜build（gzip ≤105KB）｜实机烟测（桌面 + 390/375 + 键盘路径）

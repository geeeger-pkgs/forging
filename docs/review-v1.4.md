# Forging v1.4 测评报告（资深游戏测评者视角）

> 测评日期：2026-09-15 ｜ 版本：v1.4「符文与增益」
> 测评方式：自动化测试 84 项全绿 + 蒙特卡洛数值模拟 + 代码与数据走查（实机手测顺延至 v1.5 里程碑）

## 一、版本内容回顾

1. **符文系统**：4 类效果（疾风=速度/丰饶=效率/幸运=稀有/祝福=强化成功率）× 3 档 = 12 种符文；锻造面板新增「符文」分类；配方消耗精华 + 同档锭
2. **增益槽（2 个）**：同种叠加时长（上限 60 分钟）/ 异种满槽替换剩余最短者；顶栏实时剩余分钟显示
3. **离线规则**：临时增益不参与离线结算（结算期间临时清空 buffs，结束后恢复并照常过期）——与"强化不参与离线"同构，规则一致性良好
4. **配套**：成就 40 → 43（初试符能/符文大师/双符共鸣）；每日任务 +「符文匠」；存档 v5（v1→v5 全链迁移回归）

## 二、关键数值模拟（蒙卡 6 万次）

| 场景 | +10 期望尝试 | 相对基线 |
|---|---|---|
| 基线 | 44.1 次 | — |
| 祝福一阶 +3% | 35.6 | −19% |
| 祝福二阶 +5% | 31.6 | −28% |
| 祝福三阶 +8% | 26.8 | −39% |
| 三阶 + T5 项链（+3%） | 23.2 | −47% |
| 三阶 + T5+10 项链（+4.5%） | **21.8** | −51% |

**设计判读**：祝福符文是**限时爆发**（10 分钟 ≈ 100 次尝试窗口），叠满项链后单次 +10 期望 21.8 次——刻意超模以奖励"资源动员 + 时机选择"，但需在 v1.9 全量平衡轮复核经济套利（符文成本 ≈1800 金价 vs 节省材料价值 ≈1 万金量级，套利倍数偏高）。

## 四、发现清单与处置

### 已修复（本版内闭环）
1. **[Major] 意外事故**：初版测试使用不存在的符文 id（`rune_luck_1`）——被测试套件即时拦截并纠正为 `rune_rarefind_1`，验证了"测试先行"防线的价值
2. **[Minor] 生成器日志**已含符文数量动态统计

### 观察项（v1.9 平衡轮）
- **W1 符文套利**：祝福符文的材料节省 ≈ 成本的数倍，是否需上调三阶成本或下调数值
- **W2 满叠场景**：+10 期望 21.8 次是否让"降级惩罚"体验淡化（当前判定：可接受，属终局爆发设计）
- **W3 双槽策略单一性**：是否存在"永远疾风+祝福"的固定解（待 v1.6 更多符文效果后复核）

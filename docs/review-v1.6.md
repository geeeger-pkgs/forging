## 一、版本内容回顾

1. **技能上限 50 → 100**（沿用"预留 100"的数据结构，零内核改动）
2. **经验曲线延伸**：新增分段 51+×1.03 / 76+×1.02（方案 D，模拟定档）
3. **T6 星尘 / T7 虚空**：2 座新矿脉（Lv65/80）、2 条熔炼线、9 类装备 × 2 档 = 18 件终局装备与配方
4. **体系扩展**：副属性延伸至 T7、T6+ 锻造耗煤 ×2（燃料 sink）、新档配色（星尘蓝/虚空紫）
5. **成就 46 → 52**（矿脉宗师/百尺竿头/超凡入圣/登峰造极/星尘收藏家/虚空之光）
6. **存档零迁移**：内容扩展不改变存档 schema（v6 保持），旧档直接可用

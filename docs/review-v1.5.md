# Forging v1.5 测评报告（资深游戏测评者视角）

> 测评日期：2026-09-15 ｜ 版本：v1.5「精通的传承」
> 测评方式：自动化测试 93 项全绿 + **里程碑实机烟测**（v1.5 为约定的实机验收点）+ 数值分析

## 一、版本内容回顾

1. **传承系统**：总等级 ≥120 解锁；精通点 = ⌊总等级÷10⌋ + 每个满级技能 +1；重置技能/动作/队列，保留全部资产（材料/装备/金币/成就/任务/队列位/增益）
2. **精通殿堂（6 条线）**：迅捷/智慧/富饶/洞察/离线/起点；购买退款即时、免费退点、永久生效
3. **深度集成**：精通加成接入速度（speedFor）、结算乘区（经验/效率/稀有）、离线时长（cap 8h→16h）、传承起点等级
4. **配套**：成就 43 → 46；存档 v6（v1→v6 链式迁移全测）；左栏「🔮 传承」入口

## 三、传承净收益分析（设计验证）

- **直观回报**：12 点全投迅捷 = +18% 全速 → 第二轮全程约快 15~18%；全投智慧 = +36% 经验 → 约快 26%（经验需求曲线递增放大了收益）
- **隐藏回报**：传承保留装备（满配工具 +105%+ 强化），第二轮从"裸装起步"变为"满装起步"——实测口径下第二轮到 Lv120 的耗时应比首轮低 **50% 以上**
- **结论**：传承净收益显著为正，无资产损失（零挫败），符合设计目标

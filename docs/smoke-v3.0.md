## 2. R3 口径（v3.0 修订，附数据）

**原口径**（v2.5 报告）：`tick` 与 `audio` 的 **p95 相加** ≤ 0.5ms。
**问题**：两个独立分布的分位数**不可相加**（p95(A)+p95(B) ≠ p95(A+B)），该判据系统性偏严；
实测"p50 合计 0.10~0.30ms"而"p95 合计 0.40~0.80ms"，差异全部来自 6~9 个样本里的**单个尖峰**。

**v3.0 判定口径（预先登记，见 design §2.5 / §9）**：

- **p50（同步段 + 音效调度）≤ 0.5ms** —— 常态开销；
- **max（单批总和）≤ 2ms** —— 最坏单批不超过一帧（16.7ms）的 1/8。

实测数据（三轮）：

| 轮次 | tick p50/p95/max | audio p50/p95/max | 合计 p50 / max |
|---|---|---|---|
| 修复前 | 0.20 / **0.70** / 0.70 | 0.00 / 0.10 / 0.20 | 0.20 / 0.90 |
| matchMedia 缓存后 | 0.10 / 0.30 / 0.30 | 0.00 / 0.00 / 0.00 | 0.10 / 0.30 |
| 音效激活后 | 0.20 / 0.30 / 0.30 | 0.00 / 0.50 / 0.50 | 0.20 / 0.80 |

**为达成该结果做的实现削减（不是放宽预算）**：

1. `playCue` 同步判定 + 微任务建图（v2.5 D1）；
2. **声部池**（解锁时建 8 个常驻声部）→ 播放路径零节点分配；
3. **`matchMedia` 结果缓存**（v3.0 §2.5）：把 `tick` p95 从 **0.70ms 压到 0.30ms**；
4. `off` 档在映射前短路。

## 3. R7 深渊连打与批量（真实 UI 点击）

> 说明：新号战力不足以自然通关，故用 DEV 探针**注入**"满配装备 + `bestFloor=12, stamina=12`"起始状态；
> 之后的交互全部是**真实点击**（深渊页按钮），状态读数取自 `window.__forging.state`。

| 操作（真实点击） | 期望 | 实测 |
|---|---|---|
| 点「扫荡 ×3」 | 体力 −3、结晶 = 单次×3、**只 1 条汇总提示** | ✅ 体力 12→9，结晶 0→3（第 12 层单次 1），扫荡计数 0→3，提示恰好 1 条「🕳 扫荡 ×3：+3 结晶」 |
| 选「用尽体力（9）」→ 点「扫荡 ×9」 | 一次结算剩余体力、仍只 1 条提示 | ✅ 体力 9→0，结晶 +9，扫荡计数 3→12，提示恰好 1 条「🕳 扫荡 ×9：+9 结晶」 |
| 选「×2」→ 点「挑战第 13 层起（连打 2 层）」 | 逐层判定、整次只花 1 体力、逐层补发首通、1 条提示含层数与词条名 | ✅ 体力 5→4（**只 1 点**），最高层 12→14（**2 层**），结晶 +66 = 第 13 层（试炼层 36）+ 第 14 层（裂隙层 ⌊38×0.8⌋=30），提示「🕳 连打 2 层 → 第 14 层（裂隙层）+66 结晶」 |
| 战力不足时 | 按钮置灰、不消耗体力 | ✅ 低战力注入时「挑战」按钮 `disabled`，面板显示「还差 X 战力」 |
| 面板层词条条 / 有效权重标注 | 显示「本层词条 + 下一层」，词条层权重显示 `×N` | ✅「本层词条：试炼层 / 下一层：裂隙层」 |

探针读数：`sceneDropped` 恒 **0**（全局表现层常驻生效）。

## 4. v3.0 烟测发现的缺陷（D16）

| # | 缺陷 | 证据 | 修复 |
|---|---|---|---|
| **D16** | **视图切换会卡住**：v2.5 引入的 `<Transition mode="out-in">` 要等 leave 过渡结束才挂载新视图，在"不绘制/后台"环境里离开过渡不完成 → `store.ui.view` 已变、面板内容仍是旧的 | 烟测实测：nav 高亮「深渊」、`ui.view === 'abyss'`，但 `main` 内仍是挖掘卡片，`main.innerHTML` 里没有「挑战第」 | 改为**只进不出的 CSS 动画**（`.panel { animation: panelIn 0.12s }`），不参与 Vue 过渡生命周期 → 切换永不阻塞；复测：切换后 `main` 立刻是深渊面板 |

## 5. 与 v2.5 的差异与已知边界

- 新增 R7/R8；R1~R6 沿用（R4/R5 的实现路径本版未改，v2.5 结论继续有效）。
- 层词条使可达层从 10/26/35 变为 **9/24/34**（脚本实算，见 `docs/sim-abyss-output.json`）——这是"墙"设计的一部分。
- 离线回体上限 24（仅离线段、时间比例）：单次时钟前拨上限从 12 点抬到 **24 点**（≈48 结晶），已在发布文档登记。

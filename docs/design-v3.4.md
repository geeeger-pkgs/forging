## 2. 明确不做（正式裁定，写进发布说明）

| 项 | 裁定理由（一句话） |
|---|---|
| 回收撤销（B1） | 每命令即时落盘 + `totalGoldEarned` 单调计数 + Toast 无动作模型，硬做会引入"进度入账两次"类隐性错误；已有二次确认覆盖主要误操作场景 |
| 任务/图鉴/赛季"未读"（B2） | 奖励为自动发放，无"待领取"态；徽标只对**真有待领取**的远征/教程有意义 |
| 三段教程（B5） | 章节二 8 步已覆盖符文/重铸/远征/图鉴/深渊/赛季/总等级 40，再加属新引导设计 |
| 深渊挑战/远征领取等之外的 UI 重构（底栏 sheet、行囊折叠、拖拽排序、图鉴检索） | 收益/成本不划算，且无玩家反馈支撑 |
| iOS 真机与软键盘（E1/E2） | 无设备环境（客观边界），发布说明如实声明 |
| Enter 自动化路径（E3）/ 后台静音（E4）/ 时间前拨上限（E5）/ 离线上限（E6）/ 性能口径降级（E7）/ 词缀盐（E8） | 已登记的既有取舍，逐条保留并汇总 |

## 3. 封板（v3.5）判据 —— 用户要求：**必须清光**

v3.4 结束时，未处置清单必须归零：每条只有两种终局状态 —— **完成**（有实现 + 测试 + 证据）或 **正式裁定**（有理由 + 写进 `docs/release-v3.5.md`）。
v3.5 只做四件事：

1. **终验清单七维复核**：架构（内核/壳分离、无 TODO/FIXME、依赖仅 Vue 运行时）/ 内容（全表驱动 + 校验）/ 可玩性（≥8 系统线、短中长目标、挂机纯度）/ 交互与效果（键盘可达、对比度、移动端、音效动效覆盖）/ 数值（关键曲线有 sim 证据、无套利、堆叠审计）/ 稳定性（存档 1→N 全链、长时与边界）/ 质量（测试、typecheck、build、Lighthouse 或正式口径）。
2. **全量回归**：`npm test` / `typecheck` / `build` / `gen:check` / `audit:fx:check` / `audit:content` + 实机烟测（桌面 + 375/390 + 键盘路径）+ 真实旧档迁移。
3. **发布文档 `docs/release-v3.5.md`**：版本号 3.5.0、本版变更、**已知取舍全集**（上表）、内容迁移规则、性能口径、Lighthouse 结论。
4. **最终评审**（独立资深玩家）→ Blocker 清零即封板。

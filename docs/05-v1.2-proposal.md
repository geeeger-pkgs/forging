# v1.2 提案：扩展与可玩性（评审稿）

> 起草：P10 ｜ 2026-09-15 ｜ 状态：待独立评审 → 定稿执行
> 基线：《游戏设计文档 v0.2》、v1.1 已交付（成就 29 / T4-T5 副属性 / Canvas 场景 / SVG 图标 / 存档 v2）

## 一、现状评估（玩到 Lv11~20 的真实体验）

| 维度 | 现状 | 问题 |
|---|---|---|
| 核心循环 | 挖→炼→锻→装→强 | ✅ 成立，但**中后期动作重复**（换矿脉继续挂） |
| 目标感 | 教程链（8 步）+ 成就（29） | 教程一次性；成就后**无持续目标** |
| 惊喜感 | 精华/小箱稀有掉落 | **小箱无用途**（仅回收 25 金）——死内容 |
| 决策深度 | 装备=更高档更好 | 无配装/组合决策空间 |
| 强化循环 | +0→+10 期望 44 次 | 与装备无联动（无强化辅助装备） |
| 交互 | 队列/离线/场景 | 缺「每日会话」理由；QoL 粗糙（数字不缩写、物品无详情） |

## 二、候选池与优先级

| # | 功能 | 类型 | 价值 | 成本 | 结论 |
|---|---|---|---|---|---|
| A | **任务系统**（每日 3 + 周常 1；按日期轮换；限次重掷） | 可玩性 | ★★★★★ | 中 | **P0** |
| B | **开箱系统**（工匠小箱开启：金币/精华/煤/大奖） | 扩展+惊喜 | ★★★★ | 低 | **P0** |
| C | **套装加成**（同档装备 ≥3 / ≥5 件形成套装效果） | 扩展（决策深度） | ★★★☆ | 低 | **P1** |
| D | **饰品槽扩展**（项链=强化成功率、戒指=效率） | 扩展（配装） | ★★★★ | 中 | **P1** |
| E | **QoL 包**（数字缩写 / 物品详情 / 回收全部 / 搜索 / 标题提醒） | 可玩性 | ★★★★ | 中低 | **P1** |
| F | 转生/精通过（长线循环） | 扩展 | ★★★★ | 高 | P2 → v2.0 |
| G | 更多档位（Lv65/80） | 扩展 | ★★ | 中 | 暂缓（内容量已够） |

**推荐 v1.2 范围 = A + B + C + D + E**；F 留 v2.0，G 暂缓。

## 三、详细设计（待评审要点已标注）

### A. 任务系统（P0）
- **结构**：每日 3 个 + 周常 1 个。模板池约 10 个（挖掘次数 / 制作次数 / 强化次数 / 升级 1 级 / 开箱 / 回收金币 …），生成时按难度档随机目标值与奖励。
- **进度**：记录「当日基线」（每日刷新时对各计数器快照），进度 = 当前值 − 基线。复用 stats 计数器（totalMines/totalCrafts/totalEnhances）+ 金币获得 + 开箱次数（新增计数器）。
- **轮换**：按本地日期 `YYYY-MM-DD` 刷新；周常按 ISO 周。错过不补偿（无追赶机制——待评审）。
- **重掷**：每日 1 次免费重掷某个每日任务。
- **奖励**：金币 / 精华 / 小箱（随难度档）。
- **UI**：新导航项「任务」；卡片（描述/进度条/奖励/领取按钮）；完成即领（幂等）。
- **状态**：`meta.tasks = { daily: { date, baseline: Record<counter, number>, items: [{defId, target, reward, progress, claimed}], rerollsLeft }, weekly: {...} }`（存档 v3 迁移）

### B. 开箱系统（P0）
- 「工匠小箱」右键→开启按钮（右栏资源行提供「开启」）。
- 掉落表（EV 校验目标 ≈ 40 金，高于回收 25）：
  - 金币 20~60（40%）
  - 精华 ×1~2（35%）
  - 煤 ×8~16（20%）
  - 大奖：金币 ×300（5%）
- 新增计数器 `totalCratesOpened`；开箱产生 toast + 粒子（复用场景层爆发）。
- **待评审**：EV 与回收价的关系；是否加「一键开全部」。

### C. 套装加成（P1）
- 统计当前装备中**同一档位**的件数（8 槽内）：
  - ≥3 件同档 → +2% 全技能速度
  - ≥5 件同档 → 额外 +3% 效率
- 效果计入 `aggregateEquipment`；右栏属性行显示「套装：银×4」。
- **待评审**：数值强度是否合理（与强化叠加关系）。

### D. 饰品槽扩展（P1）
- 新增 2 槽：**项链**（新属性：强化成功率 +2%~+6% 按档）、**戒指**（效率 +2%~+5%）。
- 5 档 × 2 件 = 10 件新装备 + 配方（锭 ×N + 精华 ×2，T2+ 含前档坯料）。
- 强化成功率 = `step.successRate + 项链加成`（上限 100%）；动作对话框显示实际概率。
- 影响：types（SlotId）、gen-content、stats（新聚合字段）、performEnhance、describe、RightPanel、测试。
- **待评审**：新属性「强化成功率」是否会破坏 +10 期望（44 次 → ？）；建议实测模拟后定档位数值。

### E. QoL 包（P1）
1. 数字缩写（12.3k / 4.5M）：顶栏金币/总价值、经验显示
2. 物品详情浮层：点击资源/装备 → 显示价值、用途（引用该物品的前 3 个配方）
3. 回收「全部」按钮（现有 1 / ×10 基础上）
4. 锻造/熔炼页签搜索框（按名称过滤）
5. 后台标题提醒：成就/任务完成且页面隐藏时 `document.title = "(1) Forging"`，回到页面清零

## 四、非目标（防蔓延）

- ❌ 转生/精通（v2.0 评估）；❌ 更多技能档位；❌ 交易/多人；❌ 音效；❌ 移动端专门适配（单独评估）
- ❌ 不做「错过补偿/追赶」机制（任务错过的就错过）

## 五、交付节奏（若通过）

- **v1.2a（P0）**：任务系统 + 开箱（内核 + UI + 测试 + 存档 v3 迁移）
- **v1.2b（P1）**：套装 + 饰品 + QoL 包
- 每批：typecheck/test/build 全绿 + 实机验收 + 提交

## 六、独立评审意见与仲裁（2026-09-15）

> 独立评审（tech-lead-p9 通道，成功）：2 Blocker / 3 Major / 4 Minor。以下为逐条仲裁。

| # | 评审意见 | 仲裁 | 修订动作 |
|---|---|---|---|
| B1 | 轮换×离线顺序未定义；在线跨午夜需 tick 刷新；基线须用单调累计计数器（含累计金币，禁用余额） | **接受** | 钉死顺序：加载→迁移→离线结算→轮换+快照；tick 内检测日期变化；新增 `totalGoldEarned` 单调计数器 |
| B2 | v3 迁移（槽位 8→10 预置、新计数器、tasks 缺省）；import 版本高于当前应拒绝；日期字符串比较；仅日期**前向**轮换（时钟回拨不刷奖励） | **接受** | 迁移链 v2→v3；loadGame 拒绝未来版本；日期用 `YYYY-MM-DD`/ISO 周比较 |
| M3 | 项链「强化成功率」会使 +10 期望从 44 次降至 ~38（+2%）/~30（+6%），破坏降级惩罚设计 | **接受** | **D（饰品）延后至 v1.3**，且数值须先模拟后定档（T5 拟封顶 +3%） |
| M4 | 开箱 EV 口径不成立（金币 16 + 大奖 15 + 煤 7.2 ≈ 38 + 精华计价才凑 40） | **接受** | 掉表修正：金币 20~50（40%）、精华 1~2（35%）、煤 8~16（20%）、大奖 300（3%）→ EV ≈ 38 |
| M5 | 任务规则缺口：已领→重掷、完成未领跨天、满级「升级」类任务 | **接受** | **完成即自动发奖**（消除领取边界）；重掷 1 次/日免费 + 100 金/次（上限 3）；任务池不含满级无效项 |
| m6 | 套装效果与「换更高档」同向、不可感，未产生决策 | **接受** | 套装**重设计**：≥5 件同档 → +4% 全速；8 件同档 → +4% 全速 +4% 效率（制造「混搭 vs 成套」真实决策） |
| m7 | 金币无 sink，A/B 又增金币收入 | **接受** | 重掷收费（100 金/次）作为首个持续金币 sink |
| m8 | QoL 中「强化批量/目标停损」比标题提醒价值更高 | **接受** | **「连续强化链」升入 P0**：强化动作每轮自动重臂下一级，∞ 模式连 hammer 到 +10 或材料不足；降级自动跟随当前等级 |
| m9 | 成就扩展比套装更廉价且直击「无持续目标」 | **部分接受** | 任务系统已补持续目标；成就扩展留 v1.3 |

**修订后范围**：

- **v1.2a（P0）**：任务系统（含 B1/B2/M5 修正）+ 开箱（M4 修正表）+ **连续强化链** + 存档 v3 迁移
- **v1.2b（P1）**：套装加成（重设计版）+ QoL 包（数字缩写 / 回收全部 / 搜索 / 物品详情 / 标题提醒）
- **v1.3（暂定）**：饰品槽（项链+戒指，数值先模拟）+ 成就扩展
- 存档版本：**v3**（tasks 状态 + totalGoldEarned + totalCratesOpened + 预留槽位 10）

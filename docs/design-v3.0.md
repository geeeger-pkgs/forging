# Forging v3.0 设计文档 ·「正式版」

> 阶段：① 创意 → ② 计划（本文档）→ ③ 评审（独立评审仲裁，Blocker 当版清零）→ ④ 开发 → ⑤ 测试（含实机烟测与终验）→ ⑥ 资深玩家测评 → ⑦ 发布
> 前置：v2.1~v2.5 全部完成并提交（`a034a25`，309 测试全绿，gzip 94.85KB）
> 路线图：`docs/08-roadmap-v3.md`（v3.0 标准：系统纵深 × 内容厚度 × 手感与视听 × 长线目标 四到位）

---

## 1. 定位：v3.0 是"收口版"，不是"再开一条线"

v2.1~v2.5 已经把**宽度**做够了：四技能线 × 10 装备槽、词缀与重铸、远征与伙伴、图鉴与赛季、深渊回廊、传承与精通、符文双槽、任务/成就/商店/小箱 —— **并行系统线 12 条**，内容规模 107 物品 / 92 配方 / 12 符文 / 9 词缀 / 6 伙伴 / 4 路线 / 222 图鉴条目 / 20 赛季等级 / 无限层深渊。路线图 §四「内容数量级较 v2.0 显著增长」「≥8 条并行线」**已经达成**。

所以 v3.0 的创意不是"再加一个系统"，而是**把已有内容做成一个能对外发布的完整品**：

1. **深度优先**：把"点一次就没得玩"的地方补上决策（深渊批量与层主题、重铸批量、行囊治理）。
2. **承诺清算**：把 v2.1~v2.5 遗留的 **8 条孤儿承诺**逐条落地或**正式取消**（不再挂在文档里当幽灵需求）。
3. **证据诚实**：把三处"脚本硬编码数值"改成读内容表，让"文档数字 = 脚本输出 = 内容表"在**全仓**成立。
4. **发布质量**：全量平衡审计 + 性能与体积复检 + Lighthouse 四类 ≥95 + 迁移全链回归 + 发布文档。

> **范围纪律（对抗路线图 §五"范围膨胀"风险）**：本版**不新增**技能线、不新增装备线、不做 BGM。
> 一切新内容的门槛是"能否在不引入新资源/新表的前提下加深既有系统"。

### 2.3 深渊回廊深化（P0/P1：玩家感知最强的遗留块）

**a) 层词条（L6）**：`abyssModifier(floor)` 为纯函数，确定性（`hash(floor)`），每 5 层一条、5 种效果循环，**只影响该层挑战**（不影响全局收益）：

| 层（示例） | 词条 | 效果 |
|---|---|---|
| 5n | 富矿层 | 该层战力 ×1.06（要求更高），首通结晶 ×1.5 |
| 5n+1 | 裂隙层 | 该层战力 ×0.94（更容易），结晶 ×0.8 |
| 5n+2 | 迅捷层 | 速度项权重 ×1.5（重配装有利） |
| 5n+3 | 丰饶层 | 产量+稀有项权重 ×1.5 |
| 5n+4 | 试炼层 | 强化率项权重 ×1.5 |

要求：**必须在屏上可读**（面板显示"本层词条：富矿层…"），且**权重修正后仍要过算法可达性检查**（`sim-abyss.mjs` 重算，给出三档可达层的区间）。

**b) 批量扫荡与挑战决策（L7）**
- `sweepAbyss(count)`：内核一次循环结算 N 次，只发 **1 条汇总事件** `abyssSwept{crystals, floors, count}`；UI 提供「扫荡 ×1 / ×3 / 用尽体力」。
- `challengeAbyss(target?: number)`：可选 `bestFloor+1 … bestFloor+3`；**越级挑战**额外奖励（首通时按越级数 +20%/级）；失败（战力不足）仍不消耗体力（保持既有规则）。
- 这两条把"点 12 次"与"恒选 +1"两个零决策点一起解决。

**c) 离线路径（L8）**
- 离线期间：**不自动挑战**（保持既有规则）；体力按 `REGEN_MS` 照常累计（溢出丢弃）。
- 新增：离线 ≥2 小时后，**上限临时 +6（可叠加至 18）**持续到下次挑战/扫荡结束——让"每天只上线 1 次"的纯放置玩家也能拿到 ~50% 理论体力（现在 25%）。
- 伪码与测试同步（§4 F5），并写进 `OfflineSummary`（面板提示"离线体力上限提升 +6，已生效"）。

**d) 防误删与收集完整（P0）**
- 遗物/徽记等 `totalValue === 0` 的物品：**不出现在回收列表**（UI 层），或需**二次确认**；自动回收**白名单不含**遗物/徽记。
- 图鉴计数口径统一：`codexIds('relics')` 一律以 `codex.items` 为准（不再"计数 3/3 但列表显示未收集"）。
- 补 `relic_*` / `token` 的图标（`itemArt.ts` 的 `shapeOf`），消除"无脸条目"。

### 2.4 证据链统一（P0：三件套）

现状：`sim-expedition.mjs` / `sim-season.mjs` / `sim-abyss.mjs` 仍**硬编码**数值（注释自认"提案值"），只有输出 JSON 被测试比对 —— 脚本常数与内容表可以**静默漂移**。

v3.0 统一为**三件套**（`sim-season-output.json` 已是范例）：

1. **脚本读表**：`read('expeditions.json' | 'season.json' | 'abyss.json')`，脚本内不再出现数值字面量（只保留公式）。
2. **落盘 JSON**：`docs/sim-*-output.json`，含脚本输入的**表指纹**（`JSON.stringify(table).length` + 关键字段快照）。
3. **测试逐字段断言**：`tests/*.test.ts` 断言"内容表 == JSON 输出"，并新增**反向**断言"脚本不再硬编码"（`grep` 式静态检查：脚本内不得出现被审计的数值字面量）。

另修：`sim-abyss.mjs` 的 6 处过时文案（growth 2.225× → 2.126×、"价格 ×1.5" → ×1.3、"最弱项不随 build 提升"、"券 20+永久 10"、"上不封顶的 sink"、"三技能最大值"）。

| L1 分池改变存量装备价值 | 只影响**新掉落/新锻造**；存量词缀原样保留（迁移不动），文档写明 |

| 批量扫荡放大结晶收入 | 单次收益不变（只是省点击）；`sim-abyss` 重算结晶节奏与商店价格递增的匹配 |
| 离线体力提升破坏节奏 | 上限 +6 仅**离线 ≥2h** 触发且有上限；写入 §4 F3 |
| 图鉴位图迁移出错 | 位图与逗号串**双读**（载入时任一可用）、迁移幂等、往返测试 |
| 赛季 EPOCH 变更导致正在进行的赛季重置 | 迁移保留 `renown`/`rewardedLevel`，只重算 `index`；文档写明"当前赛季剩余时间可能变化" |
| 范围膨胀（路线图 §五） | §1 的纪律：不新增技能线/装备线/BGM；所有条目都已在 backlog 中登记过 |

## 6. 验收标准（Definition of Done · 对应路线图 §四七维）

- [ ] **架构**：内核/壳层分离未破坏；`src/game` 无 DOM；依赖仍仅 Vue 运行时；无 TODO/FIXME
- [ ] **内容**：全表驱动 + 校验通过；内容规模与 v2.0 对比表（物品/配方/词缀/伙伴/赛季/深渊/图鉴条目）

- [ ] **稳定性**：迁移 1→13 全链回归；长时结算（离线上限/队列满/材料不足）边界通过
- [ ] **质量**：测试全绿（预计 ≥350）/ typecheck / build（体积增幅记录）/ audit 与 gen 同源断言
- [ ] **发布**：`09-release-v3.0.md` + 版本 3.0.0 + README 更新 + 承诺清算表复核（8/8 有终态）

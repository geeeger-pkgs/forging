**纪律升级 2（v3.4.5，「探针绿」事件）**：新断言必须**先过自探针**才算完成——

**纪律升级 3（v3.4.5，工具习惯）**：源代码修改一律用编辑器工具（Read/Write/Edit）直接落盘；

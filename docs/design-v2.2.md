## 1. 动机（创意）

v2.1 之后，游戏的**所有**进度都挂在同一条链上：采矿 → 熔炼 → 锻造 → 强化 → 词缀。这带来三个问题：

1. **单一通道**：无论你做什么，最终都要回到"锻造更好的装备"；挂机时除了换动作没有别的决策。
2. **缺少"收集"快感**：装备是消耗品，没有"我拥有这群伙伴"的归属感与图鉴目标。
3. **中期空窗**：T5 套装成型后到 T7 之间是一段纯粹的数值爬坡，缺少新系统解锁的节奏点。

v2.2 的创意落点：**开一条与锻造平行的"人"的成长线**。
- **伙伴（Companion）**：6 名可招募角色，各有稀有度、等级与**特质**（random trait）→ 收集 + 养成 + 搭配。
- **远征（Expedition）**：把伙伴编成队伍派往 4 条路线 × 3 档时长，**离线照常推进**——这才是放置游戏"睡觉也在变强"的第二条腿。
- **产出与主循环互补**：远征不产出装备，只产出材料/金币/**重铸石**与**专属遗物**；遗物是 v2.3 图鉴与后续系统的钥匙。

一句话：**锻造决定"你的装备有多强"，远征决定"你不在时世界在发生什么"。**

## 2. 系统设计（计划）

### 2.1 伙伴（Companion）

| 属性 | 说明 |
|---|---|
| 稀有度 | 3 档：平凡（1.0）/ 精锐（1.25）/ 传奇（1.6）——影响战力系数与初始等级上限 |
| 等级 | 1~30；派遣获得经验，经验满自动升级（+2% 战力/级） |
| 特质 | 4 种池随机 1 条：`勤勉`（时长 −10%）、`贪婪`（金币 +25%）、`博识`（经验 +25%）、`寻宝`（稀有产出 +30%） |
| 战力 | `等级 × 稀有度系数 × (1 + 0.02 × (等级−1))`，全队求和 |
| 招募 | 消耗「远征徽记」×N + 金币；重复获得同一伙伴 → 转化为该伙伴经验（不浪费） |
| 上限 | 6 名（全部可招募；重复招募只给经验） |

### 2.2 远征路线（4 条 × 3 档时长）

| 路线 | 解锁 | 难度（需求战力） | 主要产出 | 专属产出 |
|---|---|---|---|---|
| 近郊勘探 | 伙伴 ≥1 | 20 | 矿石 / 煤 | — |
| 废弃矿道 | 挖掘 Lv20 | 80 | 锭 / 精华 | 遗物 · 锈蚀齿轮 |
| 古代遗迹 | 锻造 Lv35 | 220 | 重铸石 / 精华 | 遗物 · 铭文碎片 |
| 深渊前哨 | 总等级 ≥150 | 600 | 大量材料 / 金币 | 遗物 · 深渊之核 |

- **时长档**：1h / 4h / 8h（产出按时长线性 + 10%/档 增益；8h 档与离线 cap 对齐）。
- **成功率**：`min(1, 战力 / 需求战力)`；成功率影响产出数量（失败仍有保底产出，避免纯挫败）。
- **派遣消耗**：每档时长消耗**补给**（锭 ×N，档位越高消耗越高）→ 给中期过剩的锭一个新出口。
- **离线结算**：远征在离线期间正常推进并结算（不消耗临时符文增益，与既有规则一致）。

### 2.3 产出与经济定位

- 目标：终局满配远征 ≈ 采矿收入的 **15%~25%**（补充而非替代），但提供**唯一**的遗物来源。
- 重铸石：遗迹路线可产出（与 v2.1 的重铸循环形成正反馈）。
- 遗物：v2.2 内用于「伙伴招募折扣」与「远征队旗帜升级」（+队伍上限/战力）；v2.3 图鉴系统接入收藏度。

## 3. 数值证据（先模拟后定档）

3. 产出/时 与各档采矿收入对比（确认 15%~25% 定位）。

## 6. 风险与对策（预登记）

| 风险 | 对策 |
|---|---|
| 远征产出让锻造贬值 | 产出定位为补充（15%~25%）；不产出装备与锭的替代品；遗物只用于远征自身与图鉴 |
| 挂机收益叠加失控 | 远征与动作结算共用离线 cap；产出走期望模式 + 小数结转 |
| 伙伴系统 UI 膨胀 | 单页三段式（伙伴/路线/进行中）；窄屏单列 |
| 与 v2.1 重铸循环冲突 | 遗迹路线产重铸石是**正反馈**设计（更多石头 → 更多重铸），非套利 |
| 招募随机性挫败 | 重复招募转经验；显示概率；徽记可从日常任务稳定获得 |

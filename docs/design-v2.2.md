## 1. 动机（创意）

v2.1 之后所有进度都挂在同一条链上（采矿→熔炼→锻造→强化→词缀）。三个缺口：

1. **单一通道**：挂机时除了换动作没有别的决策。
2. **缺少"收集"**：装备是消耗品，没有"我拥有这群伙伴"的归属感。
3. **中期空窗**：T5 套装成型到 T7 之间是纯数值爬坡，没有新系统解锁的节奏点。

v2.2 落点：**开一条与锻造平行的"人"的成长线**——伙伴（收集 + 养成 + 特质）与远征（派遣 + 离线推进 + 专属产出）。

一句话：**锻造决定"装备多强"，远征决定"你不在时世界在发生什么"。**

## 2. 系统设计（计划）

### 2.1 伙伴（Companion）

| 属性 | 规则 |
|---|---|
| 稀有度 | 平凡 R=1.0 ｜ 精锐 R=1.25 ｜ 传奇 R=1.6（**只影响战力系数**，不影响等级上限） |
| 等级 | 1~30（全稀有度一致）；**队内共享经验**：同一次远征的所有出战伙伴各获得该次经验 |
| 战力 | `L × R × (1 + 0.02 × (L − 1))`；单人满级：平凡 47.4 / 精锐 59.25 / **传奇 75.84** |
| 特质 | 4 选 1（招募时确定，可用「重掷」换，见下）：<br>`勤勉` 补给消耗 −15% ｜ `贪婪` 金币产出 +25% ｜ `博识` 伙伴经验 +25% ｜ `寻宝` 徽记/遗物概率 +30% |
| 特质重掷 | 消耗徽记 ×1 + 金币，随机换一条（避免"抽到坏特质无法挽回"） |
| 招募 | 徽记 ×3 + 5,000 金；6 名各一次，**重复招募 → 该伙伴 +300 经验**（不浪费） |
| 队伍 | 初始 **2 人**，旗帜每级 +1 人（最高 3 级 → **5 人**） |
| 旗帜 | 3 级；每级 **+8% 队伍战力（乘算，满级 ×1.24）** + 1 队伍位；升级消耗 徽记 ×5/8/12 + 金币 20k/60k/150k |

> 战力天花板（校验用）：`5 × 75.84 × 1.24 = 470.2`。

### 2.2 远征路线（4 条 × 3 档时长）

| 路线 | 解锁 | 需求战力 | 产出锚点（解锁档开采金/时） | 产出占比 | 补给（每 8h） | 徽记/8h | 专属遗物 | 经验/时 |
|---|---|---|---|---|---|---|---|---|
| 近郊勘探 | 伙伴 ≥1 | **3** | 2,812（T1） | 9% | 铜锭 ×16 | **1.0（保底）** | — | 25 |
| 废弃矿道 | 挖掘 Lv20 | **30** | 18,527（T3） | 9% | 铁锭 ×26 | 0.6 | 遗物·锈蚀齿轮 | 45 |
| 古代遗迹 | 锻造 Lv35 | **120** | 30,590（T4） | 9% | 秘银锭 ×7 | 0.5 | 遗物·铭文碎片 | 90 |
| 深渊前哨 | 总等级 ≥150 | **300** | 74,845（T7） | 9% | 虚空锭 ×9 | 0.4 | 遗物·深渊之核 | 150 |

**产出定义（可校验）**：`毛产出/时 = route.anchorGoldPerHour × ratio`，锚点为**内容表内固定值**（取自 `sim-audit.mjs` B 段），不随玩家配装漂移。
- 四线并行总毛产出 **11,410 金/时 = 终局锚点的 15.2%**（落在 15%~25% 设计目标内）。
- 产出形态：**材料 + 金币**（不产出装备，不产出锭的替代品）。

**时长档（1h / 4h / 8h）**：**速率与补给均按小时线性齐平** → 三档净/时完全相同。
- 档位是**排程选择**（多久回来看一次 / 补给的现货量），不是收益选择；显式声明以避免"只派 8h"的无脑最优解（评审 B4/§五 5.5）。
- 早期差异：1h 档只需 1.13 虚空锭即可开跑，8h 档需 9 锭库存。

**成功率与保底**：
- `成功率 = min(1, 战力 / 需求战力)`；**战力不足不阻塞**，只降低成功率与产出。
- 失败**仍有保底产出**（= 毛产出的 40%，且徽记概率减半）→ 无挫败死锁。
- 硬阻塞只有四类：**无伙伴 / 路线未解锁 / 补给不足 / 该路线槽位已有进行中的远征**。

### 2.3 产出与经济定位

- **徽记（远征徽记）**：招募与旗帜的唯一货币；来源 = 近郊保底（1 个/次）+ 其余路线概率 + **成就奖励**（`AchievementReward` 已支持 itemId）。**不依赖任务奖励 schema 扩展**（评审 B5）。实测产出 ≈ 7.5 个/日 → 招募不被卡死。
- **遗物（3 件）**：`category: 'reagent'`，**`value: 0`** → 回收按钮不产生金币，不存在"远征→遗物→金币"的第二产金通道（评审 B6）；仅用于招募折扣与 v2.3 图鉴收藏度。
- **重铸石**：古代遗迹专产 3 个/8h = **0.375 个/时**，占终局采矿重铸石产出（11.5/时）的 **3.3%**（护栏 ≤10%，采矿仍是主来源；评审 M3）。
- **补给护栏**：补给按回收价计占毛产出 **4.0%~4.1%**（≤5%）→ 不抽干锻造/强化的锭供给；深渊前哨补给仅占该档矿石产出的 **0.5%**（评审 B4）。

### 2.4 离线语义（评审 B3：七条硬规则，全部可测）

1. **cap 窗口截断**：只结算「完成时刻落在 `(lastSeenAt, lastSeenAt + counted]` 内」的远征；cap 之外的 run **保持进行中**，不结算、不丢弃。
2. **不自动续派**：每条路线**一个槽位**，同一时刻只有一个 run；离线期间不会自动开启下一轮（否则离线收益 > 在线）。
3. **派遣时扣补给**：补给在派遣瞬间扣除并持久化；领取时不再判材料（避免"离线被动作消耗后无法领取"的歧义）。
4. **随机口径**：在线用真随机（dispatch rng）；**离线走期望模式 + 小数结转**（复用 `state.meta.carry.items`，与动作结算共享小数池）。
5. **产出只由「伙伴战力 + 路线 + 时长 + 特质」决定**：**不吃**玩家装备/符文/精通/词缀的任何加成 → 在线完成与离线完成结果一致，杜绝"卡符文领取"的最优玩法。
6. **领取幂等**：领取即从 `runs` 中移除并落入 `stats`；同一次 run 不可重复领取（`runs` 持久化，重启后仍在）。
7. **时钟前拨**：与既有 `lastSeenAt` 机制同源——每次前拨最多领取**一个 cap 窗口**的收益，且受规则 1 约束（不会把"每次 8h"放大成"N×8h"）；此边界与动作侧一致，如实登记（§6）。

## 6. 风险与对策

| 风险 | 对策 / 现状 |
|---|---|
| 远征产出让锻造贬值 | 不产装备、不产锭替代品；产出 15.2% 锚点（补充线）；遗物 value 0 ✅ |

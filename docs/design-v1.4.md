# v1.4 设计稿：「符文与增益」

> 设计：资深游戏设计师视角 ｜ 状态：设计定稿，待实现
> 主题演进说明：原规划「第 5 技能·烹饪」在范围评审中演进为**「符文（锻造扩展分类） + 限时增益系统」**——更贴合挖矿锻造世界观、复用锻造技能与面板（省一套技能/教程/成就系统），把开发量集中在「增益决策」这一可玩性核心上。

## 一、设计目标

1. **给"肝"一个调节阀**：短期爆发（10 分钟增益）换长期节奏，玩家可在关键节点（冲 +10、冲新档）使用
2. **材料分流**：精华从"只服务强化"变成"强化 vs 符文"的资源抉择
3. **主动决策**：什么时候吃符文、吃哪种、叠不叠——首个真正"看时机"的系统

## 二、系统设计

### 2.1 符文（12 种 = 4 类 × 3 档）

| 符文 | 效果（10 分钟） | 档位数值 |
|---|---|---|
| ⚡ 疾风符文 | 全技能速度 | +15% / +25% / +40% |
| ✨ 丰饶符文 | 效率（产出） | +10% / +15% / +25% |
| 🍀 幸运符文 | 稀有掉落 | +20% / +35% / +60% |
| ⚒ 祝福符文 | 强化成功率 | +3% / +5% / +8% |

- 配方（锻造技能，分类「符文」）：
  - 一档（Lv1）：精华 ×3 + 铜锭 ×5 → 1 符文
  - 二档（Lv20）：精华 ×8 + 银锭 ×8 → 1 符文
  - 三档（Lv50）：精华 ×20 + 秘银锭 ×12 → 1 符文
- 物品：可堆叠；不参与强化；价值 = 材料回收价 × 0.8

### 2.2 激活规则（消耗品槽）

- **2 个符文槽**（同时最多 2 种效果）
- 激活消耗 1 个符文：
  - 同种已激活 → **叠加时长**（until += 10min，上限 60 分钟）
  - 不同种且槽满 → **替换剩余时间最短者**（toast 提示）
- 效果实时生效；到期自动移除

### 2.3 离线与增益（关键规则）

- **临时增益不参与离线结算**（与"强化动作不参与离线"同规则），离线摘要中提示
- 在线结算：按剩余 buff 时长分段模拟？—— **简化**：结算按"当前生效增益"整段应用，buff 到期时间戳照常推进（保守偏向，不刷收益）

### 2.4 数值备注（待实现时再跑模拟校验）

- 三档幸运符文 +60% 稀有 ≈ 精华掉率 1.7%→2.7%，为"补精华"专用
- 三档祝福符文 +8%：+10 期望 44.1→~29（与 T5+10 项链叠加时封顶 100%），监控与项链的复利

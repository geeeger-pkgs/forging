# Forging v1.9 测评报告（资深游戏测评者视角）

> 测评日期：2026-09-15 ｜ 版本：v1.9「磨刀石」
> 测评方式：**全量数值模拟**（scripts/sim-audit.mjs，新入仓）+ 106 项自动化测试全绿 + **里程碑实机验收**（主路径：dev 页新 UI 核验；边界路径：生产构建 PWA 首访离线开壳）+ 性能复测（LCP 174ms / CLS 0.00）+ 窄屏 480px 复验

## 一、版本内容

1. **挂账观察项清零**：v1.3~v1.8 累积的 B1~B9 九项全部处置（见 §三）
2. **精通深造**（B3）：基础上限后可购买至 2 倍，深造部分价格 ×2；退款对称；UI 显示"深造"标记与下一级价格
3. **队列位扩展至 6**（B5）：新增 5000 / 20000 / 60000 金币档（总 sink 76.5k）
4. **预设预检面板**（B6）：应用前列出每个动作的阻塞原因（缺材料/等级不足/超容量），显示"可执行 n/m"
5. **PWA 构建版本化**（B9）：vite define 注入版本 → SW 注册 `?v=` → 缓存名版本化自动清旧；install 预缓存外壳（解析入口资源）
6. **移动端细节**（B8）：`viewport-fit=cover` + safe-area padding + 100dvh + apple-touch-icon.png（180×180 实栅格化）+ iOS meta
7. **窄屏单滚动**（v1.8 W3 关闭）：≤900px 主面板改为文档流（`flex:none; overflow:visible`），消除嵌套滚动
8. **审计脚本入仓**：`scripts/sim-audit.mjs`（堆叠上限/各档产金/装备回收期/精通数学/符文经济）

## 二、平衡审计结果（B1/B2/B5/B7 证据）

### B1 速度/效率堆叠上限 —— 通过
| 项 | 满配值 | 说明 |

### B2 T6/T7 装备性价比 —— 通过
- 秘银镐→星尘镐：材料 20,621 金 / +13.8% 产出 / 回收期 ≈ **3.2 小时**
- 星尘镐→虚空镐：材料 42,676 金 / +12.1% 产出 / 回收期 ≈ **5.7 小时**
- 结论：终局装备成本与收益匹配（一次挂机时段即可回收），无"白造"或"必造到爆"问题

### B5 金币流 —— 审计通过（+ 增 sink）
- 开采产金：2,812 → 9,673 → 18,527 → 30,590 → 46,636 → 61,534 → **74,845 金/时**（逐档递增，节奏健康）
- 精炼/锻造为**设计性价值消耗**（虚空锭 245 vs 5 矿 490；自动回收使"卖矿流"成为理智的金币策略）——非 bug，属 gear-as-goal 设计
- 金币 sink 增补：队列位 6 级阶梯（300~60,000，总 76.5k）；早期重掷 100 后置成立

### B7 符文经济 —— 无套利
- 制造成本 70/480/1800 金 vs 回收价 56/224/672 → 回收亏本，"使用"是唯一正解
- 离线结算清空 buff → 无离线重复使用/离线白嫖漏洞（时长照常流逝为设计取舍，已在 v1.4 定案）

### B3 精通点数学 —— 修复后长线成立
- 基础上限买满 78 点 ≈ 早期估值 4~5 次传承；满级上限 44 点/次
- 深造后总 sink 156 点 ≈ 3.5 次满级传承，死币问题推迟到极端终局之后

## 四、发现与修复（本版闭环）

1. **[Major] 首访离线不可用**（里程碑边界测试发现）：旧策略下首次访问的资源加载发生在 SW 接管前，离线重载开壳失败 → `install` 阶段预缓存 index.html 并解析入口 assets 一并缓存 → 复验「单次在线访问 → 断网重载」完整渲染（截图证据链：离线态 nav/金币/面板全部呈现）
2. **[Minor] 队列位价格缺档**：上限 4→6 后价格表仅 4 档，非教程玩家会提前卡在"没有更多可购买" → 补 60000 档（测试发现）
3. **[Minor] 窄屏嵌套滚动**（v1.8 W3）：主面板内滚 + 外层滚动并存 → 窄屏改文档流单滚动（截图复验）

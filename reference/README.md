## 关键机制速记（实机 + wiki 交叉验证）

- 行动时间 = 基础时间 / (1 + 速度加成)；效率 = 瞬间重复（有保底 + 概率额外次数）
- 材料 7 档线：Lv1/10/20/35/50/65/80（+Lv90 天体档）
- 工具 8 档：+15% → +105% 速度加成；强化 +0→+20 再叠加
- 强化概率与「推荐等级」挂钩；+5 努力 / +10 运气 / +15 奇迹 / +20 命运
- 精华掉率 ~1.68%（低阶）→ 15%（高阶）；稀有箱 ~0.014%
- 动作可设循环 1 或 ∞；动作队列可升级扩容；离线按队列继续
- 教程：小紫牛引导任务链（挤奶 → 奶酪 → 装备 → …）
- 等级门槛：总等级解锁功能（队列槽 Lv20、背包 Lv250/500/750）
